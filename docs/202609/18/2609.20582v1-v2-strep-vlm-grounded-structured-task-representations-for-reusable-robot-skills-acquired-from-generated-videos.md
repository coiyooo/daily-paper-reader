## 摘要
人类操作视频为无需机器人演示即可获取机器人技能提供了丰富的运动与交互线索。视频生成模型可根据初始场景图像和任务指令合成此类演示，从而避免为每个任务录制演示。然而，恢复出的运动仅捕捉到一种特定场景下的实现，任务结构、几何关系和约束仍隐含其中。我们提出V2-STRep，一个零样本框架，通过基于VLM的结构化任务表示将生成视频中的运动转换为可复用的机器人技能。该表示规定了运动阶段、参考对象以及与任务相关的约束，并用最小几何结构描述目标：点、点法向、轴、平面和完整6D位姿。利用RGB-D观测将VLM提供的2D图像空间线索提升到3D，以重建任务几何结构和候选抓取位姿。几何特定的规则将运动迁移到新场景，而任务约束的轨迹优化将抓取选择与完整的机器人运动规划耦合起来。它在保留任务要求的同时，利用剩余的旋转自由度来适应关节限制。更新部署时的基础定位与约束，即可在无需生成另一个视频的情况下，按照新的兼容指令实现复用。在六个真实世界操作任务上的实验表明，相比基线方法，执行成功率有所提高，成功获取的技能能够可靠地跨场景迁移，并能适应变化的部署指令。

## Abstract
Human manipulation videos provide rich motion and interaction cues for acquiring robot skills without robot demonstrations. Video generation models synthesize such demonstrations from an initial scene image and task instruction, avoiding the need to record demonstrations for each task. However, the recovered motion captures only one scene-specific realization, leaving task structure, geometric relations, and constraints implicit. We present V2-STRep, a zero-shot framework that converts generated video motion into reusable robot skills through VLM-grounded structured task representations. The representation specifies motion phases, references, and task-relevant constraints, with targets described by minimal geometric structures: points, point-normals, axes, planes, and full 6D poses. VLM-provided 2D image-space cues are lifted into 3D using RGB-D observations to reconstruct task geometry and candidate grasp poses. Geometry-specific rules transfer motion to new scenes, while task-constrained trajectory optimization couples grasp selection with complete robot motion planning. It preserves task requirements while using remaining rotational freedom to accommodate joint limits. Updating deployment grounding and constraints enables reuse under new compatible instructions without generating another video. Experiments on six real-world manipulation tasks demonstrate improved execution success over baselines, reliable cross-scene transfer of successfully acquired skills, and adaptation to changed deployment instructions.

  - 恢复轨迹的可执行性（executability）不足。
- **整体含义**：一个**可复用技能**应明确三个要素：**保留哪些运动、相对于什么参考、在何种约束下执行**。V2-STRep 旨在将生成视频中的运动转换为这种显式、结构化、可跨场景迁移并可适应新指令的机器人技能表示，且全程**零样本**（无需机器人演示，也无需为复用重新生成视频）。

## 2. 方法论

### 2.1 核心思想

将生成视频中的物体运动与 **VLM 推断的结构化任务表示**相结合：VLM 识别运动阶段、参考系、目标几何与朝向约束；利用 RGB-D 观测将 VLM 给出的 2D 图像线索提升为 3D 任务几何与候选抓取位姿；再通过**几何特定规则**将源场景运动迁移到部署场景，最后由**任务约束轨迹优化**将抓取选择与完整机器人运动规划联合求解。

### 2.2 问题设定

- 源场景与指令 $(I_0^s, l_s)$，部署场景与兼容新指令 $(I_0^d, l_d)$；
- 使用 **Wan 2.7** 从源图像与指令生成源视频 $V_s$；
- 使用 **GPT-6 Astra** 作为 VLM，分析图像、指令与视频，推断源任务表示 $\phi_s$ 与源图像 grounding $G_s$；
- 并行地从生成视频中恢复源物体轨迹 $\tau_s = \{T_s(t)\}_{t=1}^N$；
- 部署时 VLM 分析 $I_0^d, l_d, \phi_s$，推断部署 grounding $G_d$ 与适配表示 $\phi_d$（继承源相位分解、运动参考与目标几何类型，重新评估朝向要求）。

### 2.3 结构化任务表示

表示为 $\phi_x = (g, \{\psi_k, c_k^x\}_{k=1}^K)$，$x \in \{s, d\}$：

- **目标几何 $g$**（跨所有相位共享，VLM 选择满足所有相位所需的最简几何类型）：
  - `point`：仅目标位置，目标相对朝向无关；
  - `point normal`：目标位置 + 表面法向（如竖直放置于表面）；
  - `axis`：物理/功能轴（如开门铰链）；
  - `plane`：扩展交互表面（如擦拭桌面）；
  - `full 6D pose`：完整目标坐标系。
- **相位运动结构 $\psi_k = (w_k, m_k, r_k)$**：
  - $w_k = [t_k^{start}, t_k^{end}]$ 为帧区间；
  - 运动来源 $m_k$：`retain video`（保留视频恢复运动作为参考）或 `transition`（替换为连接下一任务相关相位起始位姿的过渡运动）；
  - 参考 $r_k$（仅对 `retain video` 有效）：`phase initial`（相对相位入口物体位姿）或 `target`（相对目标几何）。
- **相位朝向约束 $c_k^x = (o_k^x, A_k^x, \rho_k^x)$**：
  - 模式 $o_k^x$：`free`（无任务朝向要求）、`axis constrained`（指定受控物体轴、参考方向及对齐关系）、`full tracking`（逐帧跟踪完整视频朝向）；
  - 剩余旋转处理 $\rho_k^x$（仅 `axis constrained` 时）：`free`（对齐轴周围旋转交给优化器）或 `fixed from video`（附加对完整视频朝向的软偏好）。

### 2.4 任务几何与抓取 grounding

- **VLM 引导的几何 grounding**：grounding $G_x$ 含 VLM 选定的像素与包围框；结合深度 $D_x$ 与相机标定 $C_x$，通过 $\Gamma_x^g = C_g(G_x, D_x, C_x)$ 重建 3D 几何：
  - `point`：目标像素反投影得 3D 位置；
  - `point normal` / `plane`：表面像素额外提供法向；
  - `axis`：沿轴像素确定方向，参考像素确定原点；
  - `full 6D pose`：用 **SAM2** 分割目标区域得 RGB-D 点云，源目标坐标系由点云初始化；用 **LoFTR** 建立源-部署图像 2D 对应，提升到 3D 后通过鲁棒配准估计刚体变换，作用于源目标坐标系得到部署目标坐标系。
- **VLM 引导的抓取 grounding**：VLM 生成 3 个抓取提案（锚点像素、指向模式、开口方向线索）。锚点反投影为 $p_i$，邻域 3D 点提供局部法向；指向模式设定 $z_i$（世界系向下或沿法向向内）；开口方向由局部法向或跨抓取宽度的两像素确定，重建后垂直于 $z_i$ 投影并归一化得 $y_i$，构造抓取位姿 $R_i = [y_i \times z_i, y_i, z_i]$；每个位姿再绕 $z_i$ 旋转 180°，最多产生 6 个候选。

### 2.5 视频运动恢复与迁移

- **运动恢复**：沿用 **Dream2Flow** 的稠密运动恢复流程，结合 **SpatialTrackerV2** 的深度预测与 **CoTracker3** 的 2D 跟踪恢复 3D 物体流；用 RANSAC 配准 + Kabsch 精化 + 时间平滑估计刚体轨迹 $\tau_s$。
- **几何条件运动迁移**（对 `retain video` 相位）：
  - **phase initial 参考**：$\Delta T_k^s(t) = T_s(t_k^{start})^{-1} T_s(t)$，$\hat{T}_k^d(t) = \hat{T}_k^d(t_k^{start}) \Delta T_k^s(t)$；
  - **target 参考**：$\hat{R}_k^d(t) = R_{s \to d}^g R_s(t)$，$\hat{p}_k^d(t) = p_g^d + R_{s \to d}^g P_g^s (p_s(t) - p_g^s)$，其中 $R_{s \to d}^g$ 对齐任务相关的源/部署几何，$P_g^s$ 选择保留的平移分量：
    - `point`：$R_{s \to d}^{point} = I$，仅平移，保留视频朝向参考；
    - `point normal`：$R_{s \to d} = R_{min}(n_s, n_d)$，最小角对齐法向，不引入绕法向的额外旋转；
    - `plane`：$R_{s \to d} = R_{min}(n_s, n_d)$，$P_s^{plane} = I - n_s n_s^\top$，保留面内运动并去除垂直于源平面的位移；
    - `axis`：先用 $R_0 = R_{min}(a_s, a_d)$ 对齐轴方向，再根据初始物体位置在轴对齐后的径向向量 $r_s, r_d$ 计算绕部署轴的附加旋转角 $\theta = \text{atan2}(a_d^\top(r_s \times r_d), r_s^\top r_d)$，$R_{s \to d}^{axis} = R(a_d, \theta) R_0$；
    - `full 6D pose`：$\hat{T}_k^d(t) = T_g^d (T_g^s)^{-1} T_s(t)$。
  - **transition 相位**：生成从上相位末位姿到后续 `retain video` 相位入口位姿的连接轨迹；若为首相位则从初始物体位姿出发。所有相位实例化并拼接后形成部署参考轨迹 $\hat{\tau}_d$。

### 2.6 任务约束机器人轨迹优化

- 对每个抓取候选 $i$，假设夹爪与物体刚体无滑连接，使用 **PyRoKi** 优化完整关节轨迹 $Q = \{q(t)\}_{t=1}^T$：
  - $Q_i^* = \arg\min_Q \lambda_p E_{pos} + \lambda_o E_{ori} + E_{robot}$；
  - 位置目标 $E_{pos} = \sum_{k=1}^K \sum_{t \in w_k} \lambda_{m,k} \|p_O(q(t)) - \hat{p}^d(t)\|_2^2$，其中 `retain video` 相位 $\lambda_{m,k}=1$，`transition` 相位 $\lambda_{m,k}=0.03$（给予更大灵活性满足机器人可行性）；
  - $E_{robot}$ 包含关节位置/速度限制、轨迹平滑、加速度正则与自碰撞惩罚；
  - 朝向目标 $E_{ori} = \sum_k \sum_{t \in w_k} \lambda_{m,k} e_{ori}(R_O(q(t)), c_k^d)$：
    - `free`：$e_{ori}=0$；
    - `axis constrained`：$e_{ori} = \beta_A e_A + \delta_k \beta_R e_F$，其中 $e_A = \|R_O(q(t)) e - v\|_2^2$ 惩罚轴错位但保留绕对齐轴的旋转自由，$\delta_k = I[\rho_k^d = \text{fixed from video}]$；
    - `full tracking`：$e_{ori} = \beta_F e_F$，$e_F = \|R_O(q(t)) - \hat{R}^d(t)\|_F^2$。
  - 在所有可行抓取-轨迹对中选择选择代价最低者，输出最终关节轨迹 $Q^*$。
