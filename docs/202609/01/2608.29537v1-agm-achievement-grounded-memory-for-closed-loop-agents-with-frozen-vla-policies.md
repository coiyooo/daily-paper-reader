## 摘要
冻结的视觉-语言-动作（VLA）策略提供了广泛的操控技能，但以开环动作块执行，不跟踪任务进度，因此智能体无法可靠地决定是继续、重试还是终止。外部记忆是一种自然的补救措施，但当尝试的动作被视为已完成的进度时，外部记忆可能有害，将局部执行错误转变为持续的任务状态错误。我们提出基于成就记忆（AGM），一种针对冻结VLA策略的轻量级闭环框架，它将任务表示为带有进度指针的子目标序列，并且仅在当前子目标通过物理证据验证后才推进该记忆。本体感觉交互线索决定何时验证，而相干点跟踪和语言条件跨视图比较（通过单个2.43M参数验证头从冻结基础模型获取）决定实现了什么。因此，AGM将开环执行转换为执行、验证和进度的闭环，保持策略冻结，无需测试时大模型推理。在RoboMME Counting基准上，AGM在PickXTimes上达到[？]在BinFill上达到[？]，平均超过最强的记忆增强基线[？]个百分点，且该框架在物理机器人上同样产生了决定性收益。因此，可靠的具身记忆更多依赖于纪律性的状态更新，而非记忆容量。

## Abstract
Frozen vision-language-action (VLA) policies offer broad manipulation skills but execute open-loop action chunks without tracking task progress, so the agent cannot reliably decide whether to continue, retry, or terminate. External memory is a natural remedy, yet it can be harmful when attempted actions are treated as completed progress, turning local execution errors into persistent task-state errors. We propose Achievement-Grounded Memory (AGM), a lightweight closed-loop framework for frozen VLA policies that represents a task as a subgoal sequence with a progress pointer and advances this memory only after the current subgoal is verified by physical evidence. Proprioceptive interaction cues decide when to verify, while coherent point tracking and language-conditioned cross-view comparison, sourced from frozen foundation models through a single 2.43M-parameter verification head, decide what was achieved. AGM thereby converts open-loop execution into a closed loop of execution, verification, and progress, keeping the policy frozen without test-time large-model inference. On the RoboMME Counting benchmark, AGM reaches on PickXTimes and on BinFill, surpassing the strongest memory-augmented baseline by points on average, and the framework yields equally decisive gains on a physical robot. Reliable embodied memory thus depends more on disciplined state updates than on memory capacity.

## 论文总结：AGM：基于成就记忆的冻结VLA策略闭环智能体

### 1. 核心问题与整体含义（研究动机和背景）

- **背景**：视觉-语言-动作（VLA）模型将视觉观察和语言指令直接映射为连续动作，在机器人操控领域展现出强大能力。然而，由于对每个下游任务进行微调成本高昂，一种实用策略是**保持策略冻结**，通过语言条件子目标来组合其技能。
- **核心问题**：冻结VLA策略以**开环动作块**执行，本身不表示、也无法从当前观测中恢复**任务进度**这一隐藏状态。在重复性、计数类操控中，任务阶段存在**感知混淆**（perceptual aliasing），例如“把物体放入容器”的当前图像无法揭示正在进行第几次重复。因此智能体无法可靠判断继续、重试还是终止。
- **关键发现**：简单引入外部记忆是有害的——若将“尝试过的动作”当作“已完成的进度”，局部的执行失误（如抓取落空、物体滑落）会被固化为**持久性的任务状态错误**，甚至比完全不用进度记忆的基线更差。
- **核心洞见**：可靠具身记忆的关键问题不是“存储什么”（what to store），而是“**何时写入**”（when to write）。一个有序子目标序列加进度指针往往就是足够的记忆，前提是每次更新都有可观测的执行证据支持，而非仅仅基于尝试的发生。

### 2. 方法论：核心思想、关键技术细节

**AGM（Achievement-Grounded Memory）** 是一个针对冻结VLA策略的轻量级闭环框架，将开环执行转变为“执行-验证-推进”的闭环。

**2.1 任务表征与记忆结构**

- 任务指令被确定性地展开为有序子目标序列 `G = {(gk, ck)}`，其中 `gk` 是提供给VLA的语言子目标，`ck ∈ {grasp, place-rev, place-irrev, other}` 是子目标类型（可恢复平面放置 vs. 不可恢复容器放置）。
- 维护紧凑任务记忆 `Mt = (G, pt)`，其中 `pt` 是指向当前子目标的进度指针，是唯一的持久任务状态。
- 冻结策略条件于索引子目标执行：`At ~ πθ(· | ot, gpt)`。

**2.2 事件触发的验证机制（when to verify）**

- 使用**滞回有限状态机**处理抓爪开度宽度 `wt`，产生事件 `et ∈ {∅, G+, R+, R0}`（稳定负载抓取、负载释放、空释放）。
- 兼容函数 `χ(et, cpt)` 仅允许“抓取事件↔抓取子目标”和“负载释放事件↔放置子目标”配对，触发验证。空释放和不兼容事件被丢弃。
- **核心原则**：交互事件仅定位“何时可能发生变化”，本身不构成成功证据。

**2.3 抓取成功验证：相干运动测试（kinematic evidence）**

- 抓取成功是一个**运动学问题**：物体是否随抓爪一致上升。
- 在抓取事件发生时，将末端执行器位置投影到前视图像，采样 6×6 查询网格；用冻结的**CoTracker3** 点跟踪器跟踪后续举升片段。
- 保留垂直位移最大的 1/3 有效轨迹，取中位数作为响应 `rG_n`；若 `rG_n ≥ δG`（4像素）则判定抓取成功。
- 这验证的是物体的实际运动，而非抓爪的命令运动；不需要训练。

**2.4 放置成功验证：语言条件跨视图比较（semantic evidence）**

- 放置成功是个**语义问题**：指令指定的物体-目标关系是否成立。
- 释放事件前后，从前视和腕部相机提取事件相关的时间聚合窗口，由冻结的 **SigLIP** 编码器生成嵌入。
- 构造事件表示 `fn`（拼接前后视图嵌入、差分、腕部视图、本体感觉摘要和语言查询嵌入），由训练过的轻量级 MLP（**2.43M参数验证头**）输出放置成功概率 `sP_n`。
- 阈值因放置类型而异：可恢复放置 `κc=0.5`（严格），不可恢复放置 `κc=0.05`（宽松，防止误拒已完成的投放）。

**2.5 成就驱动的记忆转换（memory transition rule）**

> `p+ = min(p- + 1, T)` 当验证成功时推进；
> `p+ = B(p-)`（回退到关联抓取子目标）当验证失败且子目标可恢复；
> `p+ = p-`（保持）否则。

- 支持**推进、保留、回滚**三种转换，而非简单的尝试计数。
- 提供死锁保护：连续拒绝达到上限（可恢复放置2次、不可恢复放置3次、抓取3次）时强制推进；有80步卡死超时。终端前对最近一次可恢复放置做独立视觉占用检查。

**2.6 训练**

- 仅训练验证头（2.43M参数），在788个执行事件上离线训练（RoboMME官方训练集划分，种子与评估不相交），使用类加权交叉熵。
- 数据来自AGM自身和“无验证推进”控制器，后者提供失败样本（25.1%失败率）。
- 策略、编码器、跟踪器全部冻结，部署时无需测试阶段的大模型推理。

### 6. 主要结论与发现

- **Q1**：AGM在四项任务平均值上达到55.96%，超过最强基线MemER（48.83%）7.1个百分点，几乎翻倍冻结基线的π0.5（28.78%）。PickXTimes达到100.00%（全基线中最优，此前MemER为79.33%），BinFill达到84.00%（此前最强为77.60%）。
- **Q2**：冻结的π0.5在N=1时近乎完美（100/90），但在N=5时两个任务的性能都崩溃到0：这些技能本身是存在的，它们只是缺少指定“是否继续/停止”的任务状态。AGM让PickXTimes在每一个N值下都保持100%，而BinFill的性能衰减主要与后期物理上更困难的重复填充相关，而不是进度跟踪错误。
- **跨骨干基底**：子目标条件的π0骨干自身近乎无功能，但未经任何重调、具有相同阈值的AGM配置将其提升至44.0%/8.0%，说明收益来自接口而非骨干。
- **Q3**：验证写入本身承载了大部分收益；即使在尝试-失败间隙很窄的BinFill上，仅本体感觉的变体（78.0%）也超过了最强的外部VLM基线。可恢复性感知阈值贡献集中发生在不可恢复侧（BinFill从74→84%）。
- **Q4**：在物理机器人上，完全相同的结论成立：裸策略从N=1到N=5崩溃，AGM将结果分别提升至PickXTimes100%和BinFill从60%提升到N=5的100/100/100/80/70/60。在有操作者在任务中途补充物体的情况下，经验证的计数依然正确。
- **关键洞察**：可靠的具身记忆取决于纪律性的状态更新（基于物理证据的写入），而非记忆容量或模型规模。

### 7. 优点

- **问题定位精准**：明确指出了记忆增强智能体失败的机制——尝试写入的进度记忆将瞬态故障固化为持续性任务状态错误。
- **极简设计**：2.43M参数（可训练量），231M冻结参数，无测试时大模型推理。与需要4B LoRA微调VLM的基线形成鲜明对比。
- **方法优雅且模块化**：将两种验证类型分配给最合适的冻结基础模型——点跟踪器处理运动学问题，VL编码器处理语义问题；验证时机由本体感觉局部化，通过提出训练数据的对齐问题消除与视觉无关的验证时机。
- **实验设计严谨**：训练/评估种子不相交的承诺，通过离线重放保证一致性，部署时的条件一致性检查，以及受控的消融实验。价值主张清楚：测试次数有限、指标明确（成功标准严格）、所有阈值全局共享，均未按任务微调。
- **阈值案例按恢复能力拆分**：允许基于失败代价（可恢复 vs. 不可恢复）做出不对称的接受/拒绝决策，这是一个细微的实际设计选择，已经通过消融验证了其价值。
- **物理验证**：在仿真上的研究发现转移到实体平台，包括超过演示分布深度（BinFill N=5）的情况，展示了外化进度带来的泛化收益。

### 8. 不足与局限

- **验证词汇锚定于抓握事件**：AGM只覆盖被抓取或释放括起来的子目标。推动、滑动、铰接物体操纵、持续抓取下的工具使用以及长时使用不会经过验证分支，会退回基础策略。SwingXTimes和StopCube恰好就是这样：AGM在这些指标上只匹配冻结基线，不提升。
- **任务模型是序列而非图**：单一指向有序子目标列表的指针无法表达分支计划、部分有序的子目标或在顺序外满足的目标。回滚只能对应当前重复的关联抓取，恢复能力是静态的，是在指令扩展时决定的，而不是从场景中读取的。
- **基于证据的结构信息**：子目标序列通常来自基准分解（虽然实验验证可替代解析器，略微降低性能），依赖于任务类型先验，将恢复性与放置（而不是布景）绑定在一起，忽略场景状况。
- **界限性失败模式的权衡**：为了防止死锁，指针可能被迫推进一个尚未验证的子目标，将活跃性故障转变为可能的进度错误。论文承认，它保证的是未经验证的写入“罕见且有界”，而不是“从不”。
- **任务性能受验证器性能约束**：错误接受记录未发生的进度；错误拒绝浪费预算。阈值不对称只管理这种权衡，并没有消除它。
- **物理实验规模有限**：一个6自由度平台，一个抓爪几何，一套物体类别（26×26mm立方体）。论文并未声称阈值可以跨平台移植，但校准过程是必需的，这一事实限制了直接的可复现性。
- **概率不可知论**：与最近的机器人学习文献相比，在对比基线时并没有严格的统计检验（例如检验检验、置信区间）。每格50个事件样本量是公平的，但未能报告AGM的单次方差，削弱了对比的严格性。此外，与外部实现的对比基线（SAM2Act+、SimpleSG、MemER），虽然它们使用相同的基准协议，但不太可能依赖完全相同的数据和骨干/训练时长匹配，使得跨方法的比较更像指标，而非严格的公平对照。
