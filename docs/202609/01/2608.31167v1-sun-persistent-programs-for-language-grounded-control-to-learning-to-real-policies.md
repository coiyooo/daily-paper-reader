## 摘要
在长时程操作中，基于模型的控制与学习策略之间的桥接一直存在一种隐含的分歧：控制执行明确的指定目标，学习则将这种行为摊销为反应式策略，然而现有协议丢弃了任务语义，导致奖励需要手工设计，行为偏离控制所验证的内容。我们提出语义统一（SUN）程序，这是一种类型化可执行文件，其中几何和接触关系仅定义一次，并编译为对齐的模型预测控制（MPC）代价、满足谓词、强化学习奖励、转移守卫和诊断信息。我们的系统Kuafu，由大型视觉语言系统驱动，从语言和场景语义自动合成SUN程序，通过MPC筛选可行性，并在训练阶段条件化策略时保留语义。在九项任务中，Kuafu实现了82.03%的宏观成功率，优于稀疏奖励（35.67%）和阶段行为克隆（Stage-BC，24.75%）基线。在8192路规模下，它每小时人类遥操作产生的成功轨迹时间是后者的10.57倍。每项任务使用500条轨迹时，Kuafu数据训练的DP3策略在模拟中达到46.0%的成功率（替代方案为22.4%），在物理Franka和Kinova机器人上达到34.7%。这些结果表明，经模拟筛选的任务语义可以有效地将控制摊销为鲁棒策略，无需演示或手动密集奖励，从而统一了符号规划与数据驱动的执行。

## Abstract
Bridging model-based control and learned policies in long-horizon manipulation has harbored a silent disagreement: control executes specified objectives, learning amortizes that behavior into a reactive policy, yet existing protocols discard task semantics, leaving rewards hand-crafted and behavior drifting from what control verified.We introduce Semantically UNified (SUN) Programs, typed executables where geometric and contact relations are defined once and compiled into aligned Model Predictive Control (MPC) costs, satisfaction predicates, RL rewards, transition guards, and diagnostics. Our system, Kuafu, driven by large vision language systems, automatically synthesizes SUN Programs from language and scene semantics, screens feasibility via MPC, and retains semantics while training stage-conditioned policies. Across nine tasks, Kuafu achieves 82.03% macro-success, outperforming sparse-reward (35.67%) and Stage-BC (24.75%) baselines. At 8192-way scale, it generates 10.57x the successful trajectory time per hour of human teleoperation. With 500 trajectories per task, Kuafu data trains DP3 policies to 46.0% simulation success (vs. 22.4% for alternatives) and 34.7% on physical Franka and Kinova robots. These results establish that simulation-screened task semantics can effectively amortize control into robust policies, without demonstrations or manual dense rewards, unifying symbolic planning and data-driven execution.

  - 奖励需要手工设计，且脆弱、难以调整；
  - 学习到的行为逐渐偏离控制验证过的正确行为；

- **关键观察**：控制方法可验证任务结构但依赖精确模型且需大量人工工程；学习方法适用于高维接触丰富的操作但缺乏结构化指导。两者应是互补的，但现有桥接方案（如用控制生成轨迹训练策略）丢弃了"为什么这些动作是对的"这一语义信息。
- **论文主张**：一个持久化的任务程序，在接受模拟物理的闭环筛选后存活下来，能显著提升多阶段机器人学习的效果——既保留控制验证过的语义，又将行为摊销为可部署的策略。

## 2. 方法论：核心思想、关键技术细节、公式与算法流程

### 2.1 核心思想

提出 **SUN（Semantically UNified，语义统一）程序**——一种语言接地（language-grounded）的类型化可执行工件。每条几何/接触关系只定义一次，被编译成对齐的四个接口：
- MPC成本项（`ϕ^mpc`）
- 满足谓词（`P`，用于阶段监控）
- RL奖励项（`c^rl`）
- 转移守卫与诊断信息

所有接口保留相同的**关系身份、接地对象和阶段归属**，从而消除语义漂移。

### 2.2 实现系统：Kuafu

Kuafu 的完整生命周期（如图1、图2所示）：

1. **程序合成**：LLM代理从自然语言指令 I、场景注册帧 F 和类型化算子库 L 中构建 SUN 程序 Γ（选择算子、绑定参数、组织阶段）。
2. **MPC筛选**：用任务空间非线性MPC在闭环仿真中执行候选程序，凭外部评估器 `g_ext` 判断物理成功，拒绝错误目标与转移；失败时最多尝试5次诊断修复。
3. **策略摊销**：用1000条成功的MPC轨迹训练阶段条件行为的克隆（Stage-BC）策略 `π_θ`，再冻结 `π_θ` 并训练有界残差策略 `π_ψ`（PPO）。
4. **数据生产**：保留SUN程序提供阶段注释、转移监控和假完成过滤；生成传感器-动作轨迹用于训练下游视觉策略。

### 2.3 关键公式

**SUN程序定义**（每个阶段由多条接地关系组成）：
```
Γ = {Γ_k}, k=1..K
Γ_k = {(e_{k,j}(x, ξ_k), ε_{k,j}, w_{k,j})}, j=1..m_k
```
其中 `e_{k,j}` 为接地物理关系，`ε_{k,j}` 为满足容差，`w_{k,j}` 为学习权重。

**编译映射**（每条关系编译为三个接口）：
```
Compile(Γ_k) = {(ϕ^mpc_{k,j}, P_{k,j}, c^rl_{k,j})}, j=1..m_k
```

**MPC筛选**（直接多重打靶法）：
```
min_{x_1:H, u_0:H-1} Σ_{h=0}^{H-1} ℓ_{z_t}(x̃_h)
s.t. x_0 = x_t, x_{h+1} = f(x_h, u_h)
```

**组合策略**（有界残差强化学习，式4）：
```
π(o_t, z_t) = clip(π_θ^(1)(o_t, z_t) + α_ρ·π_ψ(o_t, z_t), u_min, u_max)
```
其中 `π_ψ` 的输出以 `ρ_max` 为界。

**程序派生奖励**（式5、式6）：
- 归一化阶段得分：`S_k(x̃) = 1 - Σ w_{k,j}·c^rl_{k,j}(x̃) / Σ w_{k,j}`
- 奖励函数包含：单调进展奖励、阶段转移奖励、物理成功奖励、假完成惩罚、动作正则项。

### 2.4 学习参数校准

类似Eureka的思想，Kuafu用LLM根据训练趋势和约束满足统计来调整奖励权重、残差强度 `α_ρ` 和残差界 `ρ_max`，但**谓词容差、逻辑、接地关系、阶段顺序和项定义保持MPC接受时的取值不变**。

## 7. 优点

- **核心概念创新**：SUN程序作为持久化语义工件横跨控制、学习、数据生产全过程，解决了语义漂移问题
- **语义统一设计**：单一关系定义编译为四个对齐接口，彻底消除了各阶段间的重复实现和不一致
- **MPC作为筛选器**（而非仅轨迹生成器）：在训练前以较低成本筛选任务知识，避免无效奖励结构导致的高代价训练循环
- **独立外部评估器分离**：`g_ext` 手工编写且不暴露给LLM或策略，提供了无偏的物理成功判断
- **假完成检测**：识别SUN监控器声明成功但物理上未达标的rollout
- **有界残差设计**：冻结行为先验+有界残差学习，兼具稳定性和灵活性
- **消融设计细致**：逐层剥离组件，清晰展示每个设计元素的独立贡献
- **数据质量指标丰富**：除成功率外还报告了时间、路径长度、动作平滑度等MPC相对诊断指标
- **多架构泛化验证**：8种单任务视觉架构和3种多任务VLA均能利用生成数据

## 8. 不足与局限

### 方法局限
- **依赖注册场景接口和算子库**：需要用户提供包含对象帧和轴信息的场景注册，以及有限类型化算子库；无法处理可变形物体或流体，除非定义新算子
- **阶段单调推进**：阶段监控器不能回退，物理状态回归时无法恢复
- **有限的开放世界泛化**：未测试未见过的指令、算子、场景语义或任务组合
- **算子库设计负担**：将合成复杂度降低为"算子选择+参数绑定"，代价是构建算子库本身需要专家知识

### 实验局限
- **物理迁移规模有限**：6任务106次试验，T5仅6次试验，统计置信区间宽；未覆盖更广泛机器人平台和未结构化环境
- **视觉策略与状态策略差距明显**：如T6从87.51%（状态）降至12.70%（点云视觉），部分可观测性是显著瓶颈
- **Q95度量是MPC相对而非绝对质量**：衡量的是与特定规划器的一致性而非轨迹本身的绝对质量
- **多任务VLA性能低**：最优多任务VLA（π0.5）仅20.67%，远低于单任务水平，长期任务组合能力不足

### 潜在偏差风险
