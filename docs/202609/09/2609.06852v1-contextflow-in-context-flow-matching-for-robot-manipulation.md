## 摘要
尽管在视觉和语言领域非常有效，但将上下文学习应用于机器人技术仍然具有挑战性。现有的自回归上下文模仿方法将连续动作离散化，并通过下一个标记预测加剧了早期预测误差的累积，限制了它们在未见任务配置上的泛化能力。与此同时，流匹配策略已被探索用于连续机器人控制，并有助于减轻复合误差；然而，在流匹配框架内的上下文模仿学习仍未得到充分探索。为了解决这些局限性，我们引入了ContextFlow，一种条件流匹配模型，学习用于上下文模仿学习的连续动作分布。ContextFlow将基于流的动作预测条件建立在示范和观测之上，从而能够从嘈杂的动作分布中鲁棒地生成。为了更好地编码多模态的上下文示范，我们采用了感知器风格的多模态上下文压缩器，将视觉、本体感觉和动作序列提炼为紧凑的、与任务相关的潜在表示。在LIBERO上，ContextFlow在未见任务配置上的平均成功率比ICRT高出35个百分点，同时在不进行任何微调的情况下，匹配了特定任务微调的VLA模型π0在未见任务上的性能。在真实机器人上，它能够泛化到单臂和双臂任务的未见配置，在新的笔开帽配置上实现了40%的成功率。项目页面：https://dingjiansw101.github.io/contextflow-page/。

## Abstract
Although highly effective in vision and language domains, applying in-context learning to robotics remains challenging. Existing autoregressive in-context imitation methods discretize continuous actions and exacerbate the accumulation of early prediction errors through next-token prediction, limiting their generalization on unseen task configurations. Meanwhile, flow-matching policies have been explored for continuous robot control and can help mitigate compounding errors; however, in-context imitation learning within a flow-matching framework remains underexplored. To address these limitations, we introduce ContextFlow, a conditional flow-matching model that learns continuous action distributions for in-context imitation learning. ContextFlow conditions flow-based action prediction on demonstrations and observations, enabling robust generation from noisy action distributions. To better encode multimodal in-context demonstrations, we adapt perceiver-style multimodal context compressors that distill visual, proprioceptive, and action sequences into compact, task-relevant latent representations. On LIBERO, ContextFlow outperforms ICRT by 35 percentage points in average success rate on unseen task configurations, while matching the performance of the task-specific fine-tuned VLA model $π_0$ without any fine-tuning on unseen tasks. On real robots, it generalizes to unseen configurations of both single-arm and bimanual tasks, achieving 40% success on a new pen-uncapping configuration. ## 1. 论文的核心问题与整体含义（研究动机与背景）

- **上下文模仿学习的价值与困难**：人类能够在观察少量示范后解决新任务，这种能力在机器学习中即"上下文学习"（In-Context Learning）。尽管该方法在 NLP 和视觉领域大获成功，但在机器人操作领域应用仍充满挑战——策略需要在长视界内连续输出动作，且仅靠少量示范完成泛化。
- **现有自回归方法的缺陷**：已有上下文模仿方法（如 ICRT、LipVQ-VAE 等）大多将策略构建为自回归模型（ARM），存在两大根本局限：
  1. **误差累积**：动作逐 token 预测，早期预测误差会随 rollout 逐步传播放大，尤其在训练与评测任务配置分布不一致（unseen task configurations）时更为严重；
  2. **动作离散化**：依赖动作分词器（action tokenizer）将连续动作映射到离散 token，引入重构误差，进一步加剧执行失败。
- **流匹配的潜力与空白**：流匹配（Flow Matching）可在连续动作空间直接建模、并行输出整段动作，已被证实能缓解复合误差，但**流匹配框架下的上下文模仿学习此前未被深入探索**。论文正是针对这一空白，提出将上下文模仿学习嵌入条件流匹配框架，以实现在未见任务配置上的鲁棒泛化。

## 2. 提出的方法论：核心思想、关键技术、公式与流程

**核心思想**：构建一个条件流匹配模型 ContextFlow，以多模态上下文示范与当前观测为条件，直接建模连续动作分布，替代自回归式离散 token 预测；并通过感知器（Perceiver）风格的多模态上下文压缩器，高效提炼长序列示范中的任务相关信息。

**总体架构**（Mixture-of-Experts 设计，参考 π0）：
- **Context Expert（上下文专家）**：编码当前观测 + 压缩后的示范 token（文本指令、图像、本体状态与动作 token），形成上下文表示。
- **Action Expert（动作专家）**：处理当前本体感受与带噪动作 token，通过注意力与上下文 token 交互，执行 K 步流匹配迭代，最终输出干净的连续动作块。
- 两者间采用**块级因果注意力**（block-wise causal attention）：动作 token 可关注上下文 token，反之则不能，使上下文 token 在推理时可缓存，避免每个流匹配步重复计算。

**多模态上下文压缩器（Multimodal Context Compressor）**：
- 采用感知器风格结构：一组可学习 query token 通过交替的 cross-attention 和 self-attention 层，将各模态长序列（图像、本体状态、动作）压缩为固定大小的潜在表示，大幅降低编码与 attention 计算成本。
- 分设三个压缩器：图像压缩器（多视角共享权重）、本体状态压缩器和动作压缩器，各自输出 Nq=32 个潜在 token；输出拼接为统一上下文表示。
- 对示范序列先做时间下采样：N1=8 帧图像、N2=128 本体状态、N3=128 动作。

**条件流匹配（公式/算法流程关键要素）**：
- **插值路径**：中间分布 p_s(a^s_t | a_t) = N(s·a_t, (1−s)²I)，其中 s∈[0,1]，噪声 ε∼N(0,I)，线性插值 a^s_t=(1−s)ε+s·a_t；
- **速度场**：条件速度场闭式解 u(a^s_t | a_t)=a_t−ε，即以噪声向量至干净动作的位移作为监督；
- **训练损失**（式 2）：
  L_CFM(θ) = E_{s,a_t,ε} ‖u_θ(a^s_t, o_t, d, s) − u(a^s_t|a_t)‖²，
  其中 s∼Beta(α, β)，α=1.5, β=1；
- **推理**：用前向欧拉法从 s=0 积分至 s=1：
  a^{s+δ}_t = a^s_t + δ·u_θ(a^s_t, o_t, d, s)，默认 K=10 步；
- 动作水平线（action horizon）设为 H=50。

## 6. 论文的主要结论与发现

1. **流匹配优于自回归**：受控对比下（同视觉主干、同 π0 初始化），ContextFlow-Plain 比 ContextAR 平均成功率提升 10.5 个百分点；累积 MSE 也更低（3.0 vs. 4.7），表明流匹配在上下文模仿中能有效缓解复合误差。
2. **压缩器增益显著**：ContextFlow（带压缩器，73.5%）比 ContextFlow-Plain（64.0%）提升 9.5 个百分点，且拥有更高的推理吞吐；联合压缩视觉与状态/动作上下文、同时去除时间与空间冗余是关键。
3. **示范比文本指令更有效**：in-context 模型（ContextAR 53.5%）大幅优于仅靠文本的 OpenVLA-OFT（40.0%），说明长序列多模态示范对 unseen 任务泛化至关重要。
4. **媲美任务专用微调**：ContextFlow 无需任何微调即可持平 π0 FT（73.5% vs. 72.5%），且避免灾难性遗忘和微调成本。
5. **压缩器注意力与任务阶段相关**：可视化表明图像压缩器的 query 随任务进展关注不同区域——抓取前关注夹爪、抓取后关注物体、放置时关注目标位置区域，说明其学到了任务相关的时序信息。
6. **泛化边界**：方法在 seen 任务配置上性能接近 π0；但面对 Goal 与 Long-Horizon-10 的 unseen 任务时仍然失败（0%），说明当前方法仅支持相似原始动作原语内的视觉/空间泛化。

## 8. 不足与局限

- **泛化能力边界明显**：在 LIBERO Goal 与 10 套件的未见过任务上所有模型的成功率都是 0%，论文承认泛化仅局限于"共享底层原语的 unseen 物体/空间排布"，而非真正意义上的新任务。
- **真实实验规模有限**：每任务仅 10 次试验，统计置信度较弱；个别结果（如梨的 2/10）与方法宣称的稳健改进之间存在落差；部分任务成功率仍较低，离实际部署有明显距离。
- **计算成本偏高**：ContextFlow 需 40 A100 GPU 时，比 π0 和 ICRT 高出近一倍；虽然推理快，但训练开销较大，且主干参数较大，不利于快速迭代。
- **模型依赖初始化与预训练**：视觉编码器与动作专家从 π0 初始化并细调，若缺乏这类强预训练资源，性能是否会大幅下降尚不明确。
- **对比面不够完整**：未与近年扩散策略（如 RDT-1B 等）对比，也缺少与其他 one-shot 方法（如 Instant Policy 等）的直接比较；VLA 基线的训练条件（如 OpenVLA-OFT 的 reduced budget）可能不完全公平。
- **仿真基准的划分方式**：unseen 任务配置为预定义划分，任务间原语相近、评价范围窄；真实世界任务中 seen 与 unseen 间的偏移程度因任务而异，公平的难度标定不足。
- **随机性与方差未充分报告**：如多次随机种子下的性能波动、显式方差区间等未系统列出，影响对结论稳健性的整体判断。
