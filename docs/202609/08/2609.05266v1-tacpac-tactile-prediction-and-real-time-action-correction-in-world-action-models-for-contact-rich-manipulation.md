## 摘要
世界-动作模型利用预测的未来观测来指导动作生成，但以视觉为中心的预测会遗漏决定接触丰富操作成败的局部接触线索。然而，在我们的实验中，天真地将未来触觉观测作为附加视图进行预测，仅能恢复可实现增益的三分之一。这一差距反映了时序错配：预测先于执行，而触觉反馈在过程中才到达。我们提出TacPAC，将触觉预测转化为实时动作纠正。一旦基础模型规划好一个动作片段，TacPAC会将规划所依赖的预测接触信息与该规划自身的表示一起缓存，然后触觉专家读取每个新观测到的触觉图像，并对照该缓存来纠正尚未执行的动作。由此，反馈是相对于规划的预期来解释的，而非孤立地解释；一次纠正仅需对该缓存执行单次遍历，比重新生成整个片段便宜20.7倍。在涵盖精密插入、脆弱物体操作、物体重新定向和长时程操作的五项真实机器人任务中，TacPAC在每项任务上均取得领先，并将平均成功率从仅视觉基础模型的22%提升至64%。代码位于https://github.com/LogosRoboticsGroup/TacPAC。

## Abstract
World-action models guide action generation with predicted future observations, but vision-centric predictions miss the local contact cues that decide contact-rich manipulation. However, naively predicting future tactile observations as additional views recovers only a third of the achievable gain in our experiments. This gap reflects a timing mismatch: predictions precede execution, while tactile feedback arrives during it. We introduce TacPAC, which turns tactile prediction into real-time action correction. Once the base model has planned an action chunk, TacPAC caches the predicted contact that plan was conditioned on together with the plan's own representation, and a tactile expert reads each newly observed tactile image against that cache to correct the actions not yet executed. Feedback is thus interpreted against what the plan anticipated rather than in isolation, and one correction is a single pass over that cache, $20.7\times$ cheaper than regenerating the chunk. On five real-robot tasks spanning precision insertion, fragile-object handling, object reorientation, and long-horizon manipulation, TacPAC leads every task and raises the average from 22% for its vision-only base model to 64%. Code is available at https://github.com/LogosRoboticsGroup/TacPAC.

**核心问题：**

如何将"触觉预测"进一步转化为"执行过程中的实时动作纠正"，使机器人能够根据实际接触与预测接触之间的差异，及时修正尚未执行的动作，而不必等待整块重新规划。

**整体含义：**

TacPAC 提出了一种机制，使触觉反馈不是一个孤立的当前读数，而是对照"计划预期接触"进行解读，从而有效增强接触丰富操作中的闭环控制能力。该工作在5个真实机器人任务上的平均成功率由视觉基础模型的22%提升至64%，比最强基线高出16个百分点。

## 2. 方法论

### 2.1 核心思想

TacPAC 的核心思想是：
> 当基础模型规划出一个动作块后，将该块所依赖的"预测触觉接触"与该块自身的内部表示进行缓存；随后引入一个触觉专家，将每个最新到达的触觉图像对照该缓存进行解读，并输出对尚未执行动作的增量修正。

触觉反馈是在"计划预期了什么接触"这一背景下被解释的，而不是孤立地被解释。

### 2.2 整体架构

模型采用三专家 Mixture-of-Transformers（MoT）架构：

- **视频专家（Video Expert）**：预测未来视觉与触觉观测，输出视频潜在表示。
- **动作专家（Action Expert）**：基于预测的视频（含触觉）表示，生成规划动作块（planned action chunk）â。
- **触觉专家（Tactile Expert）**：在动作执行期间，借助当前触觉图像和缓存的触觉-动作KV，生成delta动作（Δa）以纠正未执行动作。

关键点：触觉专家与视频/动作专家共享相同的层数和注意力几何结构，从而可直接复用它们的逐层KV缓存。

### 2.3 关键技术细节

**缓存（Cache）构建：**

- 基础模型完成去噪后，对干净视频潜变量和规划动作块在流时间 τ = 0 执行一次额外向前传递，逐层存储触觉相关键值（KV）和动作相关键值（KV）。
- 之所以不直接复用最后一次去噪步骤产生的KV，是为了保证缓存代表的是干净预测而非仍含噪声的结果。
- 视觉键值不缓存，因为一个动作块内的场景变化很小，且触觉/动作键值本身是在注视视觉上下文时计算得到的。
- 缓存每个chunk只构建一次，后续每次纠正都复用它，不再访问视频专家模型。

**触觉专家：**

- 当动作块已有m步执行、第m+1帧触觉图像到达时：
  - 查询序列包含当前触觉图像（经相同tokenizer和嵌入映射到缓存对应的嵌入空间）；
  - 动作块的前m个动作用实际执行的命令替换，剩余部分保留规划值；
  - 每个动作加入一个可学习的"状态嵌入"以表示其是否已执行。
- 输出形式为逐步骤delta动作：Δa = f(I_m, â, m, C)。
- 最终修正后动作为：â + Δa。

**训练两阶段：**

- **阶段1（Stage 1）**：训练视频专家与动作专家，目标为加权的视频+动作 flow matching 损失，同时未来视觉/触觉和动作块被联合去噪。
- **阶段2（Stage 2）**：冻结阶段1所有参数，只训练触觉专家（从动作专家权重初始化）。
  - 训练数据来自冻结基础模型自身产生的规划chunk（而非真值chunk），保证训练/推理路径一致。
  - 对每个chunk均匀采样多个执行偏移 m ∈ {0,...,H-1}；
  - 对偏移m：前缀m个动作用产生触觉图像的真实命令替换；
  - 监督损失仅作用于尚未执行的后缀：

    L_tac = (1 / (H - m)) × Σ_{i≥m} ‖â_i + Δa_i − a_i‖²

  - 每个冻结计划 K = 4 个偏移共享一次前向，训练成本低。

**异步推理机制：**

- 基础模型生成动作块后机器人立即开始执行；
- 在动作执行的同时计算缓存预填充；
- 每个到达的触觉帧触发一次触觉专家前向，其产生的修正写回 m + d 及以后的未执行步骤，其中 d 是最近窗口内观测到的最大纠正延迟（以动作步计）；
- 由于单次纠正仅约30.4 ms，低于一个动作步（约33.3 ms），因此 d 在大部分执行期间为0，每步可近全覆盖未执行后缀；
- 每帧纠正都基于原始规划块 â 而非上一次纠正结果，防止错误累积传播。

## 6. 主要结论与发现

1. **整体性能领先**：TacPAC 在全部5个任务上取得最高成功率，平均成功率 **64%**，超出最强基线 T-Rex（48%）16个百分点，也大幅超过纯视觉基础模型（22%）。
2. **触觉预测单独不足**：只加触觉预测目标（不引入运行时纠正）时，平均成功率仅从22%提升至37%（约占全部增益的三分之一）；数据级证据表明：接触过渡阶段仅占4.9%的帧，却贡献了18.6%的触觉变化总和，且这些信息在任何纠正机制介入前就已随动作块一起被提交。
3. **触觉纠正与触觉预测互补**：移除触觉预测（只剩无条件纠正，平均33%）或移除触觉纠正（只剩触觉预测，平均37%），都不及完整系统；两者缺一不可。
4. **缓存的预测接触是关键**：在保持所有路径不变的条件下，阻断触觉专家对缓存中预测触觉KV的访问，使成功率从64%（TacPAC）跌至47%（w/o tactile cache），验证了"将当前触觉反馈对照预期计划进行解读"这一核心主张。
5. **实时性达标**：单次触觉纠正仅需 **30.4ms**（≈32.90 Hz），比从零重新生成动作块快约 **20.7倍**；在1.6%的纠正调用中才会出现延迟超过一个控制步的情况，机器人在绝大多数时刻能在下个动作前收到纠正结果。
6. **行为模式与直觉一致**：仅依赖触觉预测的Dream-Tac

6. **行为模式与直觉一致**：仅依赖触觉预测的Dream-Tac（48%）虽优于纯视觉（22%）和无触觉纠正条件（33%），但其提升主要来自“看到未来触觉”后更谨慎的规划；由于缺少执行期修正，一旦实际接触偏离预测（如插头角度偏了几毫米、薯片提早滑动），它只能沿用已提交的动作块，典型失败表现为卡住不动、推歪物体或挤碎目标。相比之下，完整TacPAC在同类偏移场景下能产生明显的增量纠偏——例如插入过程中检测到一侧力异常后，触觉专家会在后续步骤中生成反向的微小平移/旋转修正，使插入轨迹从“硬顶”变为“边探边进”。这种定性行为差异与此前数据级统计一致：接触过渡帧（仅占4.9%）贡献了18.6%的触觉变化量，而TacPAC正是在这些帧上触发纠正（1.6%状态下的延迟步几乎都发生在接触过渡开始瞬间），从而将预测知识转化为真正及时的反应动作。

## 7. 局限性与未来工作

**当前局限：**

- **单夹爪场景与固定基座**：所有实验均基于单机械臂和固定桌面环境，未涉及移动操作、双臂协同或抓取后再释放的完整序列；对力控精度要求更高的场景（如柔性线缆插拔）也未验证。
- **触觉传感器依赖**：InTac S1 属于高分辨率光学触觉传感器，其数据格式和嵌入空间与机器人强耦合；扩展到其他触觉传感器（如 GelSight、DIGIT、BioTac）需要重新训练tokenizer和缓存对齐模块。
- **纠正窗口受限于动作块长度**：触觉专家只能修正当前缓存的动作块内尚未执行的后缀步骤；若错误发生在块末尾或恰好块已执行完毕，则需等待下一规划周期，无法跨块持续记忆纠正状态。
- **未处理多模态长期依赖**：缓存仅包含当前块的触觉/动作KV，不含视觉KV和历史触觉上下文，因此对同一步内多次纠正、或需要数秒内连贯触觉记忆的任务支持不足。
- **训练与评估同分布**：任务设置、物体类别、初始位置均在训练分布内；没有评估对新物体、新位姿、或人类干扰的泛化性。

**潜在未来方向：**

- 将触觉缓存扩展为跨时间跨块的可重用记忆，使触觉专家能在多个动作块间维持一致的修正意图。
- 引入视觉-触觉联合上下文缓存，让触觉专家能感知场景变化而非仅依赖固定视觉注视。
- 研究自监督/在线适应机制，使触觉专家能根据实际交互结果持续微调缓存中的预期接触表示，减少对大规模离线数据的依赖。
- 探索将类似“预期-反馈对照修正”机制推广到其他非视觉模态（如力/力矩、本体感受、声学），形成通用的“世界-动作-感知”闭环范式。

## 8. 对领域的学术价值与个人评价

**学术价值：**

- TacPAC 首次明确区分了“触觉预测”和“触觉纠正”两种能力，并证明了它们的互补性。这一发现在方法层面揭示了世界-动作模型中“预测结果必须能在执行中被消费”的关键原则——预测若不能作用到尚未执行的动作上，其价值就大打折扣。
- “缓存干净预测的中间表示供专用专家在线查询”的设计，在工程上非常精巧：它避免重跑主模型、避免高延迟重新规划，让一个轻量专家以30ms量级的效果完成闭环。这种异步预填充+在线修正的推理架构，对任何基于Transformer的大模型实时控制都有参考意义。
- 消融设计严格：特别是“w/o tactile cache”一组的设置，在保留纠错与触觉预测的前提下阻断缓存读取，直接证明“当前触觉必须结合计划预期来解读”这一假设，而不仅仅是增加额外信号。

**值得商榷之处：**

- 论文未报告成功率估计的置信区间，20次试验在统计意义上区分64%与48%并不牢固；若置信度为95%，二项分布的标准误约10%，两组差异可能处边缘显著。未来应增加试验次数或提供贝叶斯估计。
- 对Dream-Tac基线的调整（gating超参数等）虽然注释为适配需要，但可能使比较并非严格“公平”——合理的做法是在官方开源配置上先运行，再报告调整带来的变化及对应成本。
- 训练数据的质量与规模叙述偏少：没有说明每个任务收集了多少demonstration、是否包含失败示范、命令执行精度等。这使读者难以判断数据多样性是否影响了纠错能力的上限。
- 触觉专家输出的是逐步骤delta，但它如何被低层控制器转换为电机指令（力的限制、平滑滤波等）未详细展开。对于易碎薯片这类力敏感任务，delta动作的幅值限制和安全性机制是关键，论文对此着墨不足。

**总体评价：**

TacPAC 是一项扎实、工程完备的触觉-世界动作模型方法。它的贡献并非提出全新的Transformer架构，而是精准识别了“预测-执行”时序错配问题，并设计出一个低成本、即插即用的纠正模块。实验结果一致支持其核心主张：将触觉反馈置于“计划预期”的背景下解读、并在动作执行期间提供增量修正，能显著提升接触丰富任务的成功率。若后续能补充统计严谨性、跨传感器泛化和长期记忆能力，该方法有潜力成为机器人触觉闭环控制的重要参照范式。
