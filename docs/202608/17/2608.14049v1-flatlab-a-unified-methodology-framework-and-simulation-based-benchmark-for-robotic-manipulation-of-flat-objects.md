## 摘要
由于不可抓取构型以及物体几何和材料的强变化性，平面物体的机器人操作具有挑战性。现有方法依赖于启发式预操作，并且通常在封闭环境中进行评估，泛化能力有限。我们提出了一个统一框架，将操作解耦为策略生成器和动作执行模块。策略生成器通过模拟数据变换和对比学习，从物体点云中学习以策略为中心、物体不变的表征，从而预测合适的操作策略。基于预测的策略，执行模块将长时序操作分解为可复用的动作原语，并动态组合它们以生成稳定的轨迹。为了实现系统性评估，我们引入了FlatLab，一个用于机器人平面物体操作的综合性仿真基准。FlatLab提供了多种刚性和可变形平面物体的高保真物理仿真、自动化的多模态数据采集，以及标准化的任务定义和评估协议。在FlatLab中进行的实验表明，我们的方法能够有效泛化到未见过的物体和类别，优于现有基线。项目页面和代码见https://flatlab-web.github.io/。

## Abstract
Robotic manipulation of flat objects is challenging due to the ungraspable configurations and strong variations in object geometry and material. Existing methods rely on heuristic pre-manipulation and are often evaluated in closed settings with limited generalization. We propose a unified framework that decouples the manipulation into a strategy generator and an action execution module. The strategy generator predicts appropriate manipulation strategies from object point clouds by learning strategy-centric, object-invariant representations via simulated data transformation and contrastive learning. Conditioned on the predicted strategy, the execution module decomposes long-horizon manipulation into reusable action primitives and dynamically composes them to generate stable trajectories. To enable systematic evaluation, we introduce FlatLab, a comprehensive simulation benchmark for robotic flat object manipulation. FlatLab provides high-fidelity physical simulation of diverse rigid and deformable flat objects, automated multi-modal data collection, and standardized task definitions and evaluation protocols. Experiments conducted in FlatLab demonstrate that our approach generalizes effectively to unseen objects and categories, outperforming existing baselines. The project page and the code are provided at https://flatlab-web.github.io/.

## 2. 提出的方法论

### 2.1 核心思想

将平面物体操作**解耦**为两个独立模块：
- **操作策略生成器（Manipulation Strategy Generator）**：从物体点云预测合适的操作策略；
- **机器人动作执行模块（Robot Action Execution Module）**：根据预测的策略，将长时程操作分解为动作原语并动态组合生成轨迹。

这种解耦设计避免模型对特定物体几何的过拟合，从而提升对未见物体和类别的泛化能力。

### 2.2 三种互补的操作策略

| 策略 | 适用对象 | 操作方式 |
|------|----------|----------|
| **Strategy-A** | 薄且小的物体（如圆盘、垫子） | 将物体推至桌边后进行侧向抓取 |
| **Strategy-B** | 厚且大的物体（如盒子、画框） | 双臂协作提升 |
| **Strategy-C** | 可变形物体（如毛巾、布料） | 挤压边缘产生可抓握的褶皱 |

### 2.3 操作策略生成器

- **输入**：物体点云 $D^{M-S}_{K-O}$；**输出**：操作策略 $P^{\hat{K}-O}_{M-S}$。
- **特征提取**：使用共享逐点变换（多层卷积+批归一化+ReLU）+全局最大池化，生成中间特征 $F^{M-S}_{K-O}$，经两层MLP预测头输出策略logits。
- **模拟数据变换（Simulated Data Transformation）**：
  - 材料变换：将可变形物体调整为刚体参数，生成对应策略标签变化的训练样本；
  - 尺度变换：在最小与最大可行尺度之间均匀采样，生成多尺度的物体点云实例。
- **多视角策略一致性（Multi-Perspective Strategy Consistency）**：
  - 对比学习框架：正样本为同一策略标签下不同物体；负样本为同一物体但不同策略标签；
  - 使用温度缩放NT-Xent损失，鼓励模型学习策略一致、物体不变的表征。
- **总训练目标**：$L_{Generator} = L_{CE} + \lambda L_{NT-Xent}$，其中 $L_{CE}$ 为交叉熵损失，$\lambda$ 为对比正则化权重。

### 2.4 机器人动作执行模块

- **输入**：场景点云 $P_{env}$ + 策略生成器输出的策略 $P^{\hat{K}-O}_{M-S}$；**输出**：6-DoF末端执行器位姿序列。
- **动作原语分解**：将长时程操作分解为可复用的原语（如接触、滑动、挤压），每个原语由起始和终止夹爪位姿定义，避免对训练物体的过拟合。
- **位姿回归**：基于PointNet++编码场景点云，两个并行MLP分别回归3D位置和旋转四元数。
- **损失函数**：
  - 位置损失：$L_{pos} = \|\hat{p} - p\|_2^2$；
  - 旋转损失：基于四元数测地距离（角误差）$L_{rot} = E[\theta^2]$，其中 $\theta = 2\arccos(|\langle\hat{q}, q\rangle|)$；
  - 总目标：$L_{Execution} = \lambda_{pos} L_{pos} + \lambda_{rot} L_{rot}$。

### 2.5 形式化表达

$$\text{Generator}(D^{M-S}_{K-O}) \Rightarrow P^{\hat{K}-O}_{M-S}, \quad \text{Execution}(P_{env}, P^{\hat{K}-O}_{M-S}) \Rightarrow D_{pc}$$

## 3. 实验设计

### 3.1 仿真平台：FlatLab

- 基于NVIDIA Isaac Sim 4.5.0构建；
- **资产规模**：104个平面物体、21个语义类别（如Book、Box、Fabric等）；18个操作场景、6类环境（卧室、厨房、洗衣房、客厅、书房、仓库）；超过10种桌面材料和纹理；
- **物理仿真**：刚体基于PhysX，可变形物体基于GPU加速的PBD（Position-Based Dynamics）；
- **机器人**：两台7-DoF Franka Emika Panda机械臂（支持单臂和双臂操纵），RMPFlow控制器；
- **数据采集**：自动化多模态数据采集（点云、RGB、深度、关节状态、末端6D位姿、成功/失败标签），支持无头模式（效率提升至少2倍）；
- **任务与评估**：标准化的任务定义（单臂接触、桌面滑动、滑至桌边、抓取、拾取、双臂触碰、协作提升、按压、挤压边缘、抓取边缘等），成功率为主指标（要求最终动作后物体悬空保持2秒不滑落）。

- **Test α**：同一类别中未训练过的物体；

## 7. 优点

- **创新性框架设计**：将策略生成与动作执行解耦，从根本上解决了“不同物体需要不同操作策略”的问题，强调策略级表征学习而非物体级特征记忆；
- **对比学习+数据变换的巧妙结合**：利用模拟数据的可变换性（材料、尺度）生成丰富训练样本，并通过对比学习实现策略一致、物体不变的表征，显著提升跨类别泛化；
- **动作原语分解**：将长时程操作分解为可复用原语，大幅降低数据采集成本，提升执行稳定性，避免了端到端VLA模型的动作抖动问题；
- **FlatLab平台贡献突出**：首个系统覆盖刚性和可变形平面物体的仿真基准，提供自动化多模态数据采集、标准化任务定义和统一评估协议，且完全可配置、可扩展；
- **实验全面性**：从仿真到真实世界、从同类别到跨类别、从单个任务到杂乱场景，多层次验证方法的有效性；
- **可复现性**：项目页面和代码公开，固定随机种子，配置确定性高。

## 8. 不足与局限

- **Sim-to-Real gap仍存在**：大部分评估在仿真环境中完成，仿真与真实世界在摩擦特性、可变形物体物理行为等存在差异（如仿真中物体易滑落、可变形物体褶皱不明显），虽然已做真实实验验证，但规模仍有限；
