## 摘要
多臂协作正成为具身操作中的核心能力。最近的视觉-语言-动作（VLA）模型整合了感知、语言与控制，但大多数模型将语言表示为单一的全局指令，并未提供显式的机制来分配和组合各臂特定行为。这种设计限制了向不同于训练期间观察到的协作模式的泛化能力。我们提出了MA-VLA，一个通过原子动作分配实现多臂协作的统一框架。MA-VLA将协作行为分解为中级原子提示，并将其分配给各个机械臂，从而实现显式的子目标指定和跨任务的组合重用。为减少对固定执行角色的依赖，我们引入了Arm Shuffle，一种在训练时对每个机械臂的观测、状态和已分配原子提示进行置换的方法。这种置换强制实现与角色无关的指令跟随，并支持重新组合成未见过的协调模式，我们称之为多臂组合泛化。我们还构建了一个基准，其中测试时的协作模式在训练集中不存在。在仿真和真实世界评估中，先前最先进的VLA在这些未见过的协作中大多失败，而MA-VLA始终成功。这些结果表明，结构化的、逐臂的原子动作分配为多臂具身系统中的可扩展泛化提供了一条实用路径。代码、模型和数据可在 https://github.com/zhangzaibin/future-robots 获取。

## Abstract
Multi-arm collaboration is becoming a core capability in embodied manipulation. Recent vision-language-action (VLA) models integrate perception, language, and control, but most represent language as a single global instruction and do not provide an explicit mechanism for assigning and composing arm-specific behaviors. This design limits transfer to collaboration patterns that differ from those observed during training. We present MA-VLA, a unified framework for multi-arm collaboration via atomic action assignment. MA-VLA decomposes cooperative behavior into mid-level atomic prompts and allocates them to individual arms, enabling explicit subgoal specification and compositional reuse across tasks. To reduce reliance on fixed execution roles, we introduce Arm Shuffle, a training-time permutation of the observation, state, and assigned atomic prompts for each arm. This permutation enforces role-agnostic instruction following and supports recomposition into unseen coordination patterns, which we term multi-arm compositional generalization. We also construct a benchmark in which test-time collaboration patterns are absent in training set. Across simulation and real-world evaluations, prior state-of-the-art VLAs largely fail under these unseen collaborations, while MA-VLA consistently succeeds. These results indicate that structured, per-arm atomic action assignment offers a practical route to scalable generalization in multi-arm embodied systems. Code, models, and data are available at https://github.com/zhangzaibin/future-robots

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：多臂机器人协作是具身智能（Embodied AI）的核心方向之一，通过并行执行与协调控制解决单臂无法完成的任务。近年兴起的视觉-语言-动作（VLA）模型虽已赋能多臂机器人遵循自然语言指令操作，但存在根本性局限：**大多数 VLA 将语言视为单一全局指令**，缺乏显式的任务分解与逐臂子任务分配机制。
- **核心问题**：在人类团队协作中，复杂目标通过"劳动分工"实现——将任务分解为中层责任并组合成连贯计划。但现有 VLA 系统的分工方式必须从数据中隐式推断，容易过度特化于少数训练协作模式，导致面对**训练时未见过的协作模式**（如新的堆叠顺序、角色互换、物体传递策略）时泛化能力极弱。
- **核心概念引入**：作者提出 **多臂组合泛化（Multi-arm Compositional Generalization）** ——在不重新训练的前提下，通过重新组合训练中见过的原子动作（如抓取、提升、对齐、放置）来应对未见过的协作执行。
- **核心研究问题**：一个学习系统能否通过重组成熟原子动作和熟悉的分工模式，来处理未见过的协作结构？

### 2. 方法论：核心思想、关键技术细节与流程

#### 总体架构

MA-VLA 是一个统一的双组件架构：

1. **VLM-based Planner（规划器）**：负责高层任务分解，输出语言级原子提示（Atomic Prompts）。
2. **VLA Executor（执行器）**：将原子提示落地为连续动作控制。

#### 关键技术一：原子提示与任务分解

- 定义**原子动作库** U = {u₁, ..., u_K}（如 grasp、lift、align、place），所有机械臂共享。
- 多臂执行被表示为"臂标记的原子动作序列"：P = [(i₁, u_k₁), ..., (i_T, u_kT)]。
- 规划器 Pφ 联合条件于高层指令 l、视觉观测 I 和原子提示集 A，一次性输出分阶段的逐臂提示序列：将指令 l 分解为 T 个原子阶段，每个阶段为 N 个臂分别分配一个原子提示（如"抓取物体""扶住碗""放置立方体"）。
- 使用 GPT-4.1 作为 VLM Planner，无需微调，但输出被约束到有限的原子提示模板集合 A 中，保证后续执行的规范性。
- 这种表征使**分工显式化**，提供了跨臂协调的简单接口。

#### 关键技术二：VLA 执行器与 Flow Matching

- 将所有臂的原子提示拼接为统一指令字符串（如 "Arm0: ..., Arm1: ..., Arm2: ..."），作为语言条件输入。
- 输入包括：多视角视觉观测（全局视图 + 各臂腕部视图）、所有臂的 proprioception 状态拼接、统一指令。
- 单次前向传播联合输出所有臂的动作向量 [a¹_t, ..., aᴺ_t]，从而捕获臂间依赖并保持协调。
- 采用 **flow-matching** 生成方式（类似 pi0）：训练时预测去噪向量场，将带噪潜在动作映射到真实动作；推理时通过积分去噪得到干净动作。
- 增加**多头投影层**，将共享潜在表示分离为各臂专属动作头。

#### 关键技术三：Arm Shuffle（核心创新）

- **问题**：若臂与固定空间角色/身份绑定，模型会过拟合固定位置或身份相关性，泛化受限。
- **方法**：训练时以概率 p_shuffle 随机置换臂的输入四元组（状态、局部视觉、原子提示、动作）：(sⁱ_t, vⁱ_t, pⁱ_t, aⁱ_t) → (s^σ(i)_t, v^σ(i)_t, p^σ(i)_t, a^σ(i)_t)，其中 σ 是臂索引的随机置换。
- **效果**：强制模型**从语义上理解原子提示而非结构性位置**，防止行为绑定到臂索引，促进角色无关（role-agnostic）的指令跟随。

#### 关键技术四：View Dropout

- 以概率 p_drop 随机遮蔽部分相机视角（将选中视角替换为全零），增强感知冗余性和多视角推理鲁棒性，应对视觉扰动。

#### 训练目标

- 两组数据扰动（Arm Shuffle 与 View Dropout）均为**纯数据层面增强**，不改变原始行为克隆（BC）损失：

L_t(θ) = E_{(O_t,l,A_t)∼D} [ Σᵢ ℓ(π_θ(Ĩ_t, sⁱ_t, pⁱ_t), aⁱ_t) ]

其中 Ĩ_t、sⁱ_t、pⁱ_t、aⁱ_t 为可能经过扰动后的输入/输出。

### 6. 主要结论与发现

1. **原子提示条件化持续提升域内多臂协作性能**，且臂数越多（3-4 臂）提升幅度越大，说明原子提示在复杂协作中能更好地消解各臂职责歧义。
2. **Arm Shuffle 是实现组合泛化的关键突破**：使模型从固定臂身份绑定中解放出来，实现从 0% 到非零的 OOD 成功率跃升。
3. **View Dropout 进一步增强了 OOD 组合泛化能力**，虽带来微小域内性能损失但整体利大于弊。
4. **统一模型优于独立模型**：分别训练单臂模型在 OOD 协作任务上几乎完全失败，且推理开销随臂数线性增长。
5. **MA-VLA 是首个在多臂组合泛化任务上取得非平凡成功率的 VLA 模型**，为多臂具身系统提供了一条实用路径。

### 7. 优点

- **问题定义有创新性**：明确形式化定义了"多臂组合泛化"问题，填补了现有研究的空白。
- **方法设计巧妙**：Arm Shuffle 简单有效——仅改变训练时数据组织方式，不改变网络结构或损失函数，即可带来质的 OOD 泛化提升。
- **可解释性**：原子提示提供人类可读的中间表征，分工显式可见。
- **统一架构可扩展**：避免了逐臂独立训练的开销和协调失败问题。
- **实验完整性好**：从仿真到真实、从域内到域外、从主实验到消融的完整验证链条。
- **公平性意识**：明确说明将单臂 VLA 基线适配到多臂输入输出接口进行公平对比。

### 8. 不足与局限

- **OOD 成功率绝对水平仍偏低**：即使在最优配置下（Three Robots Stack Cube），OOD 成功率最高仅 28%，平均约 13%；真实环境 OOD 成功率也仅 10/20、8/20、2/20、2/20，存在较大的提升空间。
- **真实环境验证范围有限**：仅验证双臂场景，未展示 3-4 臂在真实世界的组合泛化能力。
- **VLM Planner 依赖商业模型**：使用 GPT-4.1 作为规划器，虽未微调，但引入外部 API 依赖，可能带来推理成本、延迟和不确定性。
- **原子提示库需人工设计**：有限原子动作模板需任务专家预先定义，不同任务需要规则解析器生成训练标签，限制了可扩展性。
- **每任务独立训练**：所有实验均按任务单独训练，未探索多任务联合训练或预训练-微调范式的泛化收益。
- **方差信息缺失**：实验报告未提供多次独立运行的标准差或置信区间，无法评估结果稳定性。
- **消融中 Arm Shuffle 的 OOD 增益未与单纯数据增强对照**：论文未讨论更简单的数据增强（如随机臂换名而非完整置换）作为替代方案的效果。
- **评估指标单一**：仅报告成功率，缺少动作精度、完成时长、协作效率等细粒度指标。
