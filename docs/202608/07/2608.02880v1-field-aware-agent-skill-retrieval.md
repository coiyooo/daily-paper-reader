## 摘要
随着终身学习智能体积累不断增长的技能库，检索正确技能成为越来越重要的瓶颈。当前大多数技能检索方法通过将名称、描述和正文等字段拼接起来，将每个技能视为一个平面文档。然而，技能本质上是结构化的多字段对象，每个字段提供了关于技能何时以及如何使用不同信息。在这项工作中，我们研究保留这种结构是否能够提高技能检索。我们将每个技能表示为其单独组成部分，并独立计算每个字段的稀疏和稠密相似度，从而呈现出一种自然的张量化、领域感知的技能库表示。然后，我们使用均匀权重或一个小型学习型MLP来组合这些字段级分数。在两个不同的技能检索基准（SkillRet和SRA-Bench）上，我们发现保持字段分离能够提高混合检索性能，而对字段级分数进行学习则能产生最强且最一致的结果。我们的领域感知MLP在SkillRet上达到77.95的Recall@10，在SRA-Bench上达到83.78的Recall@10，优于相应的拼接学习基线。我们还发现，随着技能库变大，这一优势会更加明显，表明在检索最困难的场景下，领域感知的技能检索尤为有用。我们的结果表明，技能表示本身至关重要，而仅仅保留技能文件中已有的结构就能大幅提升检索性能。

## Abstract
As lifelong learning agents accumulate lifelong growing skill banks, retrieving the correct skill becomes an increasingly important bottleneck. Most current skill retrieval methods treat each skill as one flat document by concatenating fields such as the name, description, and body. However, skills are naturally structured, multi-field objects, where each field provides different information about when and how the skill should be used. In this work, we study whether preserving this structure improves skill retrieval. We represent each skill as its separate components, and compute sparse and dense similarities for each field independently, exposing a naturally tensorized, field-aware representation of the skill bank. We then combine these field-level scores either with uniform weights or with a small learned MLP. Across two different skill retrieval benchmarks, SkillRet and SRA-Bench, we find that keeping fields separate improves hybrid retrieval, and learning over the field-level scores gives the strongest and most consistent results. Our field-aware MLP reaches $77.95$ Recall@10 on SkillRet and $83.78$ Recall@10 on SRA-Bench, outperforming the corresponding concatenated learned baselines. We also find that the advantage grows as the skill bank becomes larger, suggesting that field-aware skill retrieval becomes especially useful in the setting where retrieval is most difficult. Our results show that skill representation itself matters, and that simply preserving the structure already present in skill files can substantially improve retrieval.

## 1. 论文的核心问题与整体含义

- **研究背景**：终身学习智能体在运行过程中会不断积累技能，形成自增长的技能库（skill bank）。当智能体面对新任务时，需要从技能库中检索出正确技能，这一环节正逐步自动化，成为智能体系统的重要瓶颈。
- **核心问题**：现有技能检索方法通常将技能视为“扁平文档”，即把名称（name）、描述（description）和正文（body）拼接成一个长字符串，再进行词法检索、稠密检索或混合检索。这种做法忽略了技能本身天然的多字段、结构化特点。
- **研究动机**：不同字段携带不同语义信息——名称和描述往往概括技能的适用条件，正文则包含详细执行步骤。拼接会稀释字段信息，导致检索精度下降，尤其在技能库变大时容易产生“技能遮挡”（skill shadowing）问题。
- **论文整体含义**：通过保留技能字段结构，用张量化表示技能库，并独立计算各字段相似度，可以显著改善智能体技能检索效果。这项工作表明“技能表示方式”本身对检索性能至关重要，而不只是依赖更强的编码器或精细的检索算法。

## 2. 论文提出的方法论

- **核心思想**：将每个技能拆分为三个独立组件（name、description、body），分别进行编码和相似度计算，避免拼接带来的信息混淆，形成“字段感知”（field-aware）的技能表示。
- **关键技术细节**：
  - 设技能库为 \(S=\{s_1,\dots,s_N\}\)，每个技能有 \(C=3\) 个组件。
  - 对组件 \(c\) 的技能 \(s_i\)，用编码器 \(\phi\) 独立编码得到向量 \(e_{i,c} = \phi(x_{i,c}) \in \mathbb{R}^d\)。
  - 将所有向量堆叠成三阶张量 \(X \in \mathbb{R}^{N\times d\times C}\)，其中 \(X_{i,:,c}=e_{i,c}\)，保留了技能、特征、组件三个模式。
  - 查询 \(q\) 编码为 \(v_q=\phi(q)\)，通过点积计算每个技能每个组件的相似度：\(M_{i,c} = X_{i,:,c}^\top v_q\)，得到矩阵 \(M \in \mathbb{R}^{N\times C}\)。
  - 经过 \(\ell_2\) 归一化后，\(M_{i,c}\) 即为余弦相似度。
- **分数融合方式**：
  - **均匀权重**：\(r_i = \frac{1}{C}\sum_{c=1}^C M_{i,c}\)，无需训练。
  - **学习权重**：使用一个小型 MLP \(f_\theta\)，输入各组件分数，输出最终技能分数：\(r_i = f_\theta(M_{i,:})\)。
- **混合检索视图**：同时使用稀疏表示（TF-IDF）和稠密表示（Qwen3-Embedding-0.6B）对每个组件独立计算相似度，因此每个查询-技能对得到 6 个分数：TF-IDF 的三个组件分数与 Qwen 的三个组件分数，即 \(z_i = [M^{tfidf}_{i,1}, M^{tfidf}_{i,2}, M^{tfidf}_{i,3}, M^{qwen}_{i,1}, M^{qwen}_{i,2}, M^{qwen}_{i,3}]\)。再将这些分数均匀平均或送入同一 MLP 做融合。

- **保留字段结构能提升检索**：在训练-free 的混合检索设置下，per-field 方法在 SkillRet 上 Recall@10 从 72.82 提升到 74.03，在 SRA-Bench 上从 70.56 提升到 74.49。
- **学习字段融合权重效果最强**：per-field + MLP 在 SkillRet 上达到 77.95 的 Recall@10 和 70.23 的 nDCG@10；在 SRA-Bench 上达到 83.78 的 Recall@10 和 68.80 的 nDCG@10，均超过拼接学习基线。
- **优势随技能库扩大而增大**：在 SRA-Bench 全库规模（26262 个技能）时，per-field MLP 比 concat MLP 高出约 7 个百分点（83.78 vs 76.52），差距在库较小时不明显，越大越显著。
- **技能表示本身很重要**：仅仅保留技能文件已有的字段结构，就能带来比拼接表示更优的检索结果。
