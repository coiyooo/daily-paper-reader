## 摘要
具身视觉运动模型，包括扩散策略（DP）和视觉-语言-动作（VLA）模型，在机器人操作基准测试中已展现出令人期待的性能。然而，其潜力仍从根本上受限于大规模具身轨迹数据集的稀缺，导致在分布外（OOD）场景中组合泛化能力不足，且捕获可复用技能结构的能力有限。为解决这一局限，我们提出基于技能的記憶（SkillMemo）框架，该框架将长时程演示隐式分解为潜在的原子技能，并将技能级特征集成到动态情景记忆库中，以解决组合任务。具体而言，我们首先引入一个基于混合专家（MoE）架构的专家引导轨迹分割模块，该模块通过学习到的门控系数将轨迹隐式划分为不同的技能原语。我们进一步设计了一种技能级情景记忆架构，将紧凑的技能表示存储为可检索的键值对。在推理期间，记忆库检索最相关的技能原语，并将其与模型当前的门控分布融合，为细化动作预测提供稳健的上下文先验。在仿真基准和真实世界操作任务上的大量实验表明，SkillMemo持续增强DP和VLA骨干模型，实现最先进的性能，并超越$π_{0.5}$，同时对未见任务配置展现出强大的组合泛化能力。

## Abstract
Embodied visuomotor models, including Diffusion Policy (DP) and Vision-Language-Action (VLA) models, have demonstrated promising performance on robotic manipulation benchmarks. However, their potential remains fundamentally constrained by the scarcity of large-scale embodied trajectory datasets, leading to insufficient compositional generalization in out-of-distribution (OOD) scenarios with limited capability to capture reusable skill structures. To address this limitation, we propose Skill-Based Memory (SkillMemo) framework that implicitly decomposes long-horizon demonstrations into latent atomic skills and integrates skill-level features into a dynamic episodic memory bank for solving compositional tasks. Specifically, we first introduce an expert-guided trajectory segmentation module built upon a Mixture-of-Experts (MoE) architecture, which implicitly partitions trajectories into distinct skill primitives represented by learned gating coefficients. We further design a skill-level episodic memory architecture that stores compact skill representations as retrievable key-value pairs. During inference, the memory bank retrieves the most relevant skill primitives which are subsequently fused with the model's current gating distribution, providing a robust contextual prior to refine action predictions. Extensive experiments on the simulation benchmark and real-world manipulation tasks demonstrate that SkillMemo consistently enhances both DP and VLA backbones, achieving state-of-the-art performance and outperforming $π_{0.5}$, while exhibiting strong compositional generalization to unseen task configurations.

- **本文核心主张**：将长时程轨迹**隐式分解为原子技能**，并将技能级特征存入**动态情景记忆库**，通过检索与组合实现强组合泛化——这是解决数据稀缺下组合泛化问题的关键路径。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架

SkillMemo 由两大核心模块组成：

1. **专家引导轨迹分割模块（EGTS）**：基于 Mixture-of-Experts（MoE）架构，将整条轨迹隐式分解为一系列潜在原子技能。
2. **技能级记忆架构（SLMA）**：以键值对形式存储技能表征，推理时检索最相关技能并与当前门控分布融合，从而精化动作预测。

### 2.2 关键技术细节

**EGTS—专家引导轨迹分割：**

- 不同于显式分割（手动划分技能边界），采用 MoE 架构实现**隐式、数据驱动的技能发现**。
- 给定中间特征 $h_t$，MoE 层计算：

$$y_t = \sum_{i=1}^{N} g_i(h_t) \cdot E_i(h_t)$$

其中 $E_i$ 为第 i 个专家网络，$g_i$ 为其门控权重。
- 直觉上，每个专家捕获一个**可复现的局部运动基元**，门控网络通过随时间调制专家激活来**隐式定义时间分割边界**。
- 为促进专家间技能特化与互补，引入基于**部分信息分解（Partial Information Decomposition, PID）**的协同信息损失：

$$L_{PID} = -\left[ I(\{A,B\};G) - I(A;G) - I(B;G) \right]$$

最小化该损失鼓励专家联合表征比各自单独表征包含更多任务相关信息，从而驱动专家学习**互补且不重叠**的技能。
- 辅助使用**专家负载均衡损失**和 **top-k 路由**策略防止专家坍缩。

**SLMA—技能级记忆架构：**

- **记忆存储**：每个技能段以其中心特征作为键 $k_m = \frac{1}{L}\sum_{t \in \tau_m} h_t$（时间聚合压缩表征）；值 $v_m$ 为该段内全部时间步的门控权重序列 $\{g(h_t)\}_{t \in \tau_m}$。最终记忆库 $\mathcal{M} = \{(k_m, v_m)\}_{m=1}^{M}$。
- **记忆检索**：推理时计算当前状态特征 $q_t$ 与所有记忆键的余弦相似度，取 top-N 条目；并设置**置信度阈值 δ** 进行可靠性校验。
- **检索融合**：若检索可靠，将检索到的门控分布与当前预测分布进行加权平均：

$$g'(q_t) = \lambda g(q_t) + (1-\lambda)\frac{1}{N}\sum_{n=1}^{N} v_n[t']$$

其中 λ 控制记忆干预强度。通过这种方式，模型可基于已知技能基元**合成未见行为**。
- **记忆更新**：采用使用频率跟踪机制，在记忆库达到容量上限 $M_{max}$ 时，按三条标准优先淘汰：①时间戳最久远；②长期未被检索；③始终低于可靠性阈值的低质量条目。这实现了记忆库的**动态精简与持续学习**。

### 2.3 算法流程概述

1. **训练阶段**：骨干模型前向传播 → MoE 门控将轨迹隐式分割为技能段 → 每个技能段生成紧凑键值对 → 存入记忆库；
2. **推理阶段**：当前观测特征与记忆键计算相似度 → top-N 检索 + 可靠性校验 → 将检索到的门控分布与当前预测融合 → 输出精化后的动作。

## 6. 主要结论与发现

1. **SkillMemo 一致提升多种骨干性能**：
   - π0.5-SkillMemo 在 LIBERO 上平均成功率 98.0%，较 π0.5（96.8%）提升 **1.2%**，超越 MemoryVLA（96.5%）**1.5%**；

3. **技能隐式分割的有效性得到验证**：
   - 门控权重可视化显示，专家激活在关键动作阶段（如抓碗、开火）出现显著峰值，说明 MoE 在无显式标注下自发形成语义有意义的技能特化；
   - EGTS 单独即可带来一致提升，进一步叠加 SLMA 增益更大。
4. **强组合泛化能力**：
   - 在 Goal 套件训练后直接评估 Spatial 套件，达到 75.6%，**甚至超过在 Spatial 上显式训练的无记忆基线**（72.1%）；
   - 真实世界评估中，未见组合 Strawberry on Plate 成功率从 DP 的 65.0% 提升至 75.0%。
5. **专家数量存在效率与精度平衡**：N=5 为最佳折中，超过后精度提升趋缓而推理时间大幅增加。

## 7. 优点与亮点

- **"隐式分割 + 显式记忆"的创新融合**：不同于静态技能库或纯隐式行为分割，SkillMemo 将 MoE 技能发现与动态情景记忆相结合，实现了技能的结构化存储与组合检索；
- **无需人工技能标注**：技能发现完全由门控机制数据驱动，避免了显式分割对先验知识的依赖；
- **PID 正则化设计精巧**：利用信息论工具鼓励专家间互补特化，有理论支撑；
- **记忆检索具有可解释性**：门控分布作为记忆值既紧凑又保留了时域动态，检索融合机制清晰直观；
- **跨骨干通用性强**：同一框架对 DP 和多种 VLA 骨干均有效；
- **真实世界验证了组合泛化**：不仅做单任务评测，还专门设计了物体-容器新组合的零样本迁移实验，实验设计具有针对性。
