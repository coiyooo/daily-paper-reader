## 摘要
动作分块通过预测多个未来动作来缩短机器人模仿学习的有效决策视野，而传统的相位条件描述的是当前控制时刻。当预测视野跨越程序边界时，将当前相位分配给整个块会产生结构性时间不匹配。我们提出了TRACT，它将相位结构的动作分块分解为可接受的当前相位和未来视野内的单一当前到下一边界。任务局部图约束时序阶段权威性，累积边界分布单调地将未来查询路由到相位特定的查询和动作路径。对于接触执行，因果响应缺失积分器将策略意图与已确认的后续运动进行比较，当方向性响应被抑制时累积手臂补偿，并在确认恢复后衰减。在六个真实机器人变体、每次十次试验的设置下，完整TRACT实现了10/10的全序列成功，99.00 [88.75, 100.00]%的中位数[最小值, 最大值]擦拭完成度，零观测相位歧义，以及零停顿。在当前完整方法包和评估设置下，路由表示比平坦包获得了更好的观测任务结果（6/10对3/10成功；77.08%对8.03%的中位擦拭完成度）。时序权威性将观测相位歧义从8/10降至0/10，响应积分将停顿从4/10降至0/10。包比较并未将路由与其他生成器包差异隔离。

## Abstract
Action chunking shortens the effective decision horizon of robot imitation learning by predicting multiple future actions, while conventional phase conditioning describes the current control instant. When a predicted horizon crosses a procedural boundary, assigning the current phase to the entire chunk creates a structural temporal mismatch. We present TRACT, which factorizes phase-structured action chunking into an accepted current phase and a single CURRENT-to-NEXT boundary inside the future horizon. A task-local graph constrains chronological phase authority, and a cumulative boundary distribution monotonically routes future queries through phase-specific query and action paths. For contact execution, a causal response-deficit integrator compares policy intent with ACK-eligible subsequent motion, accumulates arm compensation when directional response is suppressed, and decays after confirmed recovery. Across six real-robot variants with ten trials each, full TRACT achieves 10/10 full-sequence success, 99.00 [88.75, 100.00]% median [min, max] wipe completion, zero observed phase ambiguity, and zero stalls. Under the current complete method package and evaluation setting, the routed representation obtains better observed task results than the flat package (6/10 vs. 3/10 success; 77.08% vs. 8.03% median wipe completion). Chronological authority reduces observed phase ambiguity from 8/10 to 0/10, and response integration reduces stalls from 4/10 to 0/10. The package comparison does not isolate routing from other generator-package differences.

# TRACT：具有时序阶段权威性的时间路由动作块用于接触密集操作

## 1. 核心问题与研究动机

### 背景
- 长时程接触密集操作（contact-rich manipulation）要求机器人依次完成取工具、建立接触、维持运动、归还工具等一系列流程，且相似状态在不同阶段指向不同的合法动作。
- 动作分块（action chunking）通过一次性预测多步未来动作来缩短决策周期，典型代表为 ACT（Action Chunking with Transformers）。

### 核心问题
- 传统相位条件化（phase conditioning）只将“当前相位”赋值给整个未来动作块，但预测视野内可能跨越程序边界（如 P2 → P3），导致整块沿用旧相位，产生结构性时间错配。
- 论文总结了三种典型失败模式：相位切换后动作转换延迟、过早推进相位导致擦拭终止、以及物理响应被抑制时的相位一致停摆。

### 关键洞察
- 存在两种不同的时间尺度上的歧义：
  - **当前相位歧义**（present-phase ambiguity）：当前物理瞬时哪个阶段有效；
  - **未来边界歧义**（future-boundary ambiguity）：预测块是否跨入下一阶段、何处跨入。
- 这两类决策应分别处理，不能混为一体。

## 2. 方法论

### 核心思想
TRACT 将相位结构化的动作分块分解为两个独立决策：
1. **当前相位接受**（present-phase acceptance）：由时序权威机制负责；
2. **未来边界路由**（future-boundary routing）：由单调 CURRENT→NEXT 边界负责。

### 关键技术细节

#### 2.1 问题形式化
- 策略输出三元组：接受相位 `c_t`、块内边界 `k_t`、未来动作块 `A_t = {a_t,j}`。
- 路由规则：查询 `j < k_t` 使用当前相位语义，`j ≥ k_t` 使用合法后继相位语义；`k_t = H` 表示块内无边界。

#### 2.2 时序阶段权威（Chronological Phase Authority）
- 共享编码器提供观测记忆，分别驱动相位预测器、边界估计器和动作生成器。
- 相位头输出原始 logits → 诊断性相位提议 `e`。
- 权威头以先前接受的相位为条件，输出推进证据 `p_adv`。
- 确定性的 Phase Manager 综合原始提议、推进证据、返工证据和有效时钟信号，输出受限于任务局部图 `L(c_{t-1}) = {c_{t-1}, n(c_{t-1})} ∪ R(c_{t-1})` 的接受相位。
- 一次接受切换原子性地更新相位、清除不兼容的分块/时序集成谱系，并以新相位生成全新分块。

#### 2.3 单调块内路由（Monotone Intra-Chunk Routing）
- 边界估计器输出分类分布 `π_t(k)`，累积分布得到 NEXT 门控 `γ_{t,j}`，单调不降。
- 路由查询：`Q_j = (1-γ)Q(current)_j + γQ(next)_j`。
- 动作解码同样采用同一单调门控混合相位特异的残差路径：`a_j = H_shared(z_j) + (1-γ)R_current(z_j) + γR_next(z_j)`。
- 该表示的单调性保证在动作解码前成立，振荡或无关相位序列零表示支持。

#### 2.4 因果响应缺失积分器（Causal Execution Closure）
- 用于处理物理接触中意图与实际运动不一致的问题。
- 比较策略意图与实际响应（仅沿已确认的 ACK 执行谱系），沿当前策略方向累积“响应缺失”状态。
- 通过方向余弦相似度 ρ 估计响应率，累积缺失后以相位特异性增益生成手臂补偿指令；确认方向速度恢复后以指数衰减消减补偿。
- 补偿仅修改手臂吸引子，不改变相位、路由和夹爪语义。

## 7. 优点

- **问题刻画精准**：明确区分“当前相位歧义”与“未来边界歧义”两种时间尺度，概念清晰且具有理论说服力。
- **消融设计严谨**：六个变体形成递进对比链，能够相对干净地归属各机制贡献（尤其是 TR vs TF 同检查点切换，TP vs TR 同策略不同权威）。
- **方法新颖**：将相位语义赋予决策时域（CURRENT-to-NEXT 单一边界 + 累积分布门控），突破了传统“当前相位条件化整块”的限制。
- **因果性保障**：响应积分器仅使用因果可用的执行证据（ACK 谱系、方向恢复确认），不依赖未来信息，工程上具有部署价值。
- **考虑实际硬件因素**：包含夹爪语义、安全监督、别名监督、时间轴对齐等工程细节，体现了真实机器人部署的系统性。
- **诚实报告局限**：自述单场景、包级比较局限、非统计推广研究，透明度较好。

## 8. 不足与局限

### 实验覆盖不足
- 仅一个平面擦拭任务、一种机器人、一种接触场景，无法说明方法在更多类型的接触密集操作（如装配、打磨、插拔）中的适用性。
- 每种条件仅 10 次试验，统计功效有限，未见显著性检验或跨种子方差分析。

### 评估偏差风险
- Tour 包比较（TU vs TR）混入了除路由外其他生成器包差异，如论文自述“不隔离路由与其他生成器包差异”。
- 观测相位歧义依赖于人工外部评审，可能存在一定主观性。
- 实验结果以观测任务结果为主，未深入分析内部相位输出的完整闭环正确率。

### 方法局限
- 单一边界假设：即每块仅允许一次 CURRENT→NEXT 转换。跨度覆盖两次转换则需多个边界；分支图需后继选择机制。
- 返工边（P4→P2）通过重置谱系处理，不是真正的多边界认知，本质上绕开了问题。
- 响应积分器参数（上升时间、衰减时间、相位速度阈值）需要任务级调参，泛化到新任务时需要重新设计。
- 需要专家标注的相位标签或可推导的程序顺序作为监督源，对示范数据的结构化程度有一定依赖。

### 应用限制
- 阶段图需要显式定义，非结构化或隐式阶段的任务难以直接套用。
- 所有证据均为单机器人可行性层面，如论文自述，不能作为跨任务推广性或总体层面性能的统计结论。
