## 摘要
视觉-语言-动作（VLA）模型的主流构建方式是将预训练的VLM与单独训练的条件流匹配动作专家耦合在一起。这使得VLM成为上下文编码器而非决策者。我们引入了G0.5，一个预训练的自回归VLA模型，其中单个Transformer解码器在单一目标下同时生成推理和动作标记。三个组件使其在基础模型规模下易于处理：一个可学习的跨具身动作分词器，将异构机器人动作映射到共享词汇表；一个原生思维链流，将任务分解、物体接地和动作提示与动作标记交错排列；以及一个视觉记忆模块，通过视觉编码器注入多秒历史信息。由于推理和动作共享同一组权重，预训练VLM的能力得以迁移到物理行为中：模型能紧密遵循指令，且提示可直接控制动作粒度、任务时域和分布外场景处理，而无需进一步训练。G0.5在大量机器人数据集和VQA样本上预训练，在7个独立测试场景中超越了最先进模型：在R1lite和R1pro机器人上的真实世界微调（76.7%对比π_{0.5}的53.3%和GR00T-N1.7的24.4%）；使用通用策略在2025年BEHAVIOR挑战赛的50个长时域家庭移动操作任务中（31.4%对比π_{0.5}的26.3%和挑战赛冠军的26.1%）；DROID后训练随后零样本迁移到未见环境和物体（82.5%）；语言跟随的拾取与放置基准LIBERO（98.9%）；RoboTwin 2.0（93.3%）；以及SimplerEnv-Bridge（87.3%）。

## Abstract
The prevailing recipe for Vision-Language-Action (VLA) models couples a pretrained VLM with a separately trained flow-matching action expert. This makes the VLM a context encoder rather than a decision-maker. We introduce G0.5, a pretrained autoregressive VLA in which a single transformer decoder emits reasoning and action tokens under a single objective. Three components make this tractable at foundation-model scale: a learnable cross-embodiment action tokenizer that maps heterogeneous robot actions into a shared vocabulary; a native chain-of-thought stream interleaving task decomposition, object grounding, and action hints with action tokens; and a visual memory module that injects multi-second history through the vision encoder. Because reasoning and action share a single set of weights, the pretrained VLM's capabilities carry over to physical behavior: the model follows instructions closely, and prompts directly steer action granularity, task horizon, and out-of-distribution scene handling without further training. Pretrained on a large collection of robot datasets together with VQA samples, G0.5 surpasses state-of-the-art models across 7 independent regimes: real-world fine-tuning on R1lite and R1pro robots (76.7\% vs.\ 53.3\% for $π_{0.5}$ and 24.4\% for GR00T-N1.7), the 2025 BEHAVIOR Challenge on 50 long-horizon household mobile manipulation tasks using a generalist policy (31.4\% vs.\ 26.3\% for $π_{0.5}$ and 26.1\% for the challenge winner), DROID post-training followed by zero-shot transfer to an unseen environment and objects (82.5\%), a language-following Pick-and-Place benchmark, LIBERO (98.9\%), RoboTwin 2.0 (93.3\%), and SimplerEnv-Bridge (87.3\%).

# G0.5：面向机器人推理与动作的单一自回归流——论文深度解析

## 1. 核心问题与研究动机

**背景与痛点：**
- 当前视觉-语言-动作（VLA）模型的主流架构是"VLM-as-encoder"范式：预训练VLM仅作为上下文编码器，将视觉和语言条件编码后，交给一个**单独训练的流匹配（flow-matching）或扩散动作专家**生成连续动作。
- 这一范式存在根本性矛盾：**VLM被降级为条件编码器而非决策者**，其核心生成能力——链式推理（CoT）、上下文学习（in-context learning）、基于提示的动件引导——只能通过压缩的条件瓶颈间接影响行为，无法原生参与动作生成。
- 早期自回归VLA（如RT-2、OpenVLA）虽让VLM直接产生动作，但面临**动作token化效率瓶颈**：连续动作的逐维离散化在高频控制下产生大量token，导致推理缓慢、成本高昂。

**核心论点：**
- 作者主张回归自回归路线，但通过**学习式动作分词器（ActionCodec）** 大幅压缩动作token，使VLM在保留推理能力的同时直接作为动作生成器。论文的核心承诺是：*感知、推理、动作应在单一自回归过程中、共享同一token词汇表与同一组权重*。这一设计使VLM的预训练能力（推理、语言遵循、场景理解）能直接迁移至物理行为，而非被"封装"在外部模块中。

## 2. 方法论：G0.5的三块基石

### 2.1 整体架构
- 初始化自 **Qwen3.5 2B** 预训练视觉-语言模型。
- 模型接收多视角RGB观测、具身标识（embodiment id）、自然语言指令和本体感觉状态，**自回归生成结构化输出**，最终以离散动作码序列收尾。
- 训练采用标准**下一token交叉熵损失**，仅在生成段（CoT推理 + 动作码）上计算——推理和动作在同一个解码器、同一个前向过程中产生，无需辅助回归目标或专家蒸馏。
- 推理选项中额外提供一个可选的流匹配头（与π0.5架构一致），条件于自回归主干的隐藏状态，作为对比和可选部署方案。

### 2.2 跨具身结构化动作分词器（Cross-Embodiment ActionCodec）
这是解决VLM推理效率瓶颈的关键组件：

- **结构化分解**：将异构机器人动作分解为语义对齐的运动部件（左臂、右臂、夹爪、下半身），每个部件pad到共享最大维度，所有具身统一映射到 **27维统一动作空间**（左臂9 + 左夹爪1 + 右臂9 + 右夹爪1 + 下半身7）。
- **残差向量量化（RVQ）**：采用多层残差量化器，逐级细化动作重构精度，将连续动作压缩为紧凑离散码。
- **时间对比学习**：引入时间对比目标，使时间上相邻的相似动作映射到相近的token序列，提升token一致性、降低VLM训练时的优化噪声。
- **稀疏激活预测**：在token序列中显式注入结构化特殊token，仅对当前活跃的DoF组生成8个动作码，不活跃部分**不产生任何token**，极大减少解码负担（如双手机器人只有左臂移动时，右臂的token组完全不出现在流中）。

### 2.3 原生思维链（Native Chain-of-Thought）
- 构建四种自描述推理目标：**Subtask**（原子子任务分解）、**BBox**（关键物体边界框）、**Trace**（2D夹爪运动轨迹）、**ActionHint**（帧级动作提示）。
- 每个训练步从8种CoT组合中随机采样一种（包括无CoT基线），所有组合在同一下一token目标下监督。
- 与ECoT、CoT-VLA等将推理模块"外挂"在编码器式骨干上的方案不同，G0.5的CoT token与动作token**共享同一解码器、上下文和目标**，推理与动作是同一生成过程的耦合阶段，而非两个分离阶段。
- 推理时CoT模式可**在无需重新训练的情况下自由切换**（通过提示模板控制）。

### 2.4 视觉记忆（Visual Memory）
- 借鉴π0.7和MEM的设计，在Vision Transformer内**每四层插入分解式空间-时间注意力模块**，在时间步与空间patch间交替混合信息，融合多秒级历史视觉上下文。
- 在最后一层丢弃所有历史token以严格约束计算延迟；训练时随机丢弃历史帧（30%概率）防止过拟合；用连续状态嵌入替代离散文本tokenizer同步本体感觉输入。

### 2.5 自动标注流水线与预训练数据
- 构建自动化多模态标注流水线：规则化时间分段 + Gemini 3 / Doubao Seed 2.0 Pro生成多粒度语言注释；SAM3跟踪生成逐帧边界框和分割掩码；正向运动学将3D末端轨迹投影到头相机平面生成2D Trace。
- 预训练混合：**14种具身**的机器人演示数据 + Web级VQA / 具身VQA / 室内标注数据，统一在同一自回归解码器中以相同交叉熵损失优化。

## 6. 主要结论与发现

1. **统一自回归VLA在标准指标上全面超越SOTA**：LIBERO 98.9%、RoboTwin 2.0 93.3%、SimplerEnv-Bridge 87.3%、DROID零样本迁移82.5%（远超π0.5-DROID的57.5%）、真实机器人微调76.7%（π0.5为53.3%、GR00T-N1.7仅24.4%）。
2. **单checkpoint超越多checkpoint方案**：BEHAVIOR挑战赛上，仅单epoch后训练的G0.5已达0.2904，超过π0.5（4 epochs，0.2626）和四checkpoint冠军方案（0.2605）；4 epochs后进一步提升至0.3136。
3. **AR动作监督保护而非削弱VLM能力**：PP Bench上G0.5零样本语言跟随率（65.6%）超过π0.5经50H后训练的水平（68.8%仅略高，而1H/10H设置下π0.5几乎失效），直接反驳了"AR动作训练会破坏VLM预训练能力"的担忧。
4. **结构化动作分解带来分解式全身控制先验**：BEHAVIOR中导航-操作交替任务（搬箱到储藏室、捡垃圾、装车）增益最大，说明将移动与操作在token空间中解耦有效。
5. **CoT在长时域阶段条件任务中提升明显**：五阶段Air Fryer任务中AR+CoT进度分从2.4提升至3.8，Cook Bacon从1.5提升至3.4；但单阶段PP Bench中CoT几乎无增益（<1.6pp），说明CoT的收益集中在需要逐阶段接地与执行的任务结构中。
6. **AR策略天然适合RL**：在GRPO微调中，AR策略相比FM策略收敛更快、最终成功率更高（97.4% vs 92.9%）、run-to-run方差更低——源于token级对数概率的直接可计算性。
7. **提示词可操控物理行为**（定性观察）：副词限定词（"用力推"）、空间线索（"垂直"）、近义动词替换（press/push in/close）可改变AR+CoT的滚动执行结果，暗示提示级行为引导的潜力。

## 7. 优点与亮点

- **架构性论证清晰**：论文不满足于"我们更优"的经验结论，而是通过PP Bench语言跟随、BEHAVIOR训练效率、RL兼容性三方面证据论证AR路径的**结构性而非偶然性优势**，逻辑自洽且有说服力。
- **动作分词器的工程创新**：结构化部件分解（而非扁平化）+ 稀疏激活 + 时间对比学习，将跨具身动作token化的效率与一致性提升到基础模型可用规模，是VLA工程实践的重要贡献。
- **推理与动作的深度耦合**：CoT token与动作token在同一流中共享注意力，使推理结果能直接调节动作生成（AR头受益远大于FM头），验证了"推理指导执行"的机制性价值。
- **评估覆盖面罕见地全面**：从真实机器人到仿真、从桌面操作到家庭移动操作、从单臂到双人形上半身、从零样本到RL，几乎覆盖了VLA评估的所有关键维度。
- **对失败模式保持诚实**：坦诚报告了抽屉插入、半透明柜体等弱项，以及预训练数据分布对容器交互类任务的限制，提出了明确的改进路径。
- **训练效率显著**：单epoch后训练即超越基线4-epoch水平，展示预训练表征的高质量。

## 8. 不足与局限

- **预训练算力与数据细节缺失**：未报告预训练的GPU数量、总时长、数据规模等关键信息，第三方复现门槛高。
- **DROID零样本的视觉对比弱点**：作者自己承认G0.5在低对比半透明表面（无标记抽屉）上定位能力弱于基线（60% vs 90%），加标记后性能剧增（100%），说明视觉接地仍有环境依赖。
- **提示级行为操控仅为定性观察**：样本量极小（n=5）、未系统量化，且作者承认AR与FM的CoT轨迹因rollout发散而不同，机制解释（"解码接口假说"）尚未直接验证。
- **FM头对比的公平性存疑**：附加的流匹配头是否为"最佳调优"的FM架构未充分论证，AR优势可能部分来自FM头实现的质量差异。
- **长时域记忆仍有限**：视觉记忆仅覆盖秒级历史，无法解决真正的长时域任务记忆（如跨房间、跨数分钟的物体位置记忆）。
- **下半身控制未独立评估**：虽然统一动作空间包含下半身，但未单独拆解评估导航能力的贡献。
- **分布外泛化证据有限**：主要OOD验证来自DROID（环境/物体层面留出）和PP Bench（物体类别层面），但真实世界的OOD场景多样性和复杂性远未穷尽。
- **某些挑战赛任务完全失败**：BEHAVIOR中多任务得分为0（如组装相框、整理书籍存储、制作披萨），说明仍存在显著能力盲区。
- **零样本CoT的正确性依赖人工评分**：主观性较强，缺乏自动评估协议。这些失败模式也提示当前方法在细粒度/高频控制（如低对比表面定位）上仍需感知层面的增强，而非仅靠自回归架构解决。
