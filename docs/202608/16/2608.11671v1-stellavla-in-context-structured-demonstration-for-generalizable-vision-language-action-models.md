## 摘要
视觉-语言-动作（VLA）模型能够遵循指令并操作物体，但当场景、视角或物体与训练时不同，其性能常常在分布外（OOD）情况下崩溃。适应每种新情况通常需要收集更多数据并进行微调。我们提出了StellaVLA，一个通过在测试时基于单条检索演示进行条件化调整的框架。关键思想是超越模仿专家行为，转而传达原因：一个自动化的离线流程将每条原始轨迹转换为结构化演示，例如任务计划、子目标描述和口头化的3D运动，且无需人工标注。作为情境指导提供，这种结构化演示让策略推理任务而非模仿像素轨迹，这也使其能够跨具身（真实机器人、人手或XR演示）迁移。一种并行双训练设计通过联合动作与语言目标在训练期间内化这种推理，而推理时仅使用动作专家，保持实时、高频控制且无额外延迟。在VLA-Arena排行榜（2026年8月1日）上，StellaVLA以总分0.63排名第一，而强先验模型（$\pi_{0.5}$和LingBot-VLA）分别为0.44和0.22，并在LIBERO上以98.8%的平均成功率、LIBERO-Plus上以85.1%的成功率进一步领先。我们的真实机器人基准表明，StellaVLA能够利用人类/机器人演示和人类到机器人（XR）演示作为情境结构化演示，帮助VLA模型适应OOD任务。

## Abstract
Vision-Language-Action (VLA) models can follow instructions and manipulate objects, but their performance often collapses out of distribution (OOD), when the scene, viewpoint, or object differs from training. Adapting to each new situation typically requires collecting more data and fine-tuning. We present StellaVLA, a framework that instead adapts at test time by conditioning on a single retrieved demonstration. The key idea is to move beyond imitating what an expert did and instead convey why: an automated offline pipeline converts each raw trajectory into a structured demonstration, e.g., a task plan, sub-goal descriptions, and verbalized 3D motion, at zero human-annotation cost. Provided as in-context guidance, this structured demonstration lets the policy reason about the task rather than mimic a pixel trajectory, which also makes it transferable across embodiments (real-robot, human-hand, or XR demonstrations). A parallel dual-training design internalizes this reasoning during training through a joint action-and-language objective, while inference uses the action expert alone, preserving real-time, high-frequency control with no added latency. On the VLA-Arena leaderboard(Aug 1, 2026), StellaVLA ranks first with an overall score of 0.63, versus 0.44 and 0.22 for the strong prior models ($π_{0.5}$ and LingBot-VLA), and it further leads on LIBERO with 98.8% average success rate and LIBERO-Plus with 85.1% success rate. Our real-robot benchmark demonstrates that StellaVLA can use both human/robot demos and human-to-robot (XR) demos as in-context structured demonstration to help VLA model adapt to OOD tasks.

## 一、核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型在场景、视角或物体与训练分布不同时，性能会大幅下降（OOD 崩溃）。传统解决方式需要重新收集数据并微调，成本高、难以扩展。
- **核心问题**：如何在不更新模型参数的前提下，让 VLA 模型在测试时快速适应新任务/新环境？
- **现有方案（ICIL）的不足**：已有的 In-Context Imitation Learning 方法将检索到的原始轨迹（观测序列+连续动作）直接作为上下文前缀，只让策略"看到专家做了什么"，却未传达"为什么这样做"。模型容易把演示当噪声，退回到预训练先验（行为惯性），难以泛化。
- **核心假设**：如果能把演示转化为显式的"推理结构"（任务计划、子目标、运动语义），策略模仿的就是专家的推理过程而非像素轨迹，从而获得更强的 OOD 泛化能力。

## 二、方法论

**核心思想**：将检索到的单条演示转化为"结构化演示"（任务计划 + 子目标语义 + 2D/3D 运动语言化），作为上下文条件引导 VLA 策略；训练时用并行的语言专家监督内化推理，推理时移除语言专家、仅保留动作专家，实现零额外延迟。

**1. 离线结构化上下文提取（零人工标注）**
- 原始轨迹 τ = {(o_t, a_t)}，可来自真实机器人遥操作、人手跟踪或 XR 重定向等异构来源。
- 因果式语义分割：用现成的 VLM（如 Qwen3-VL）将轨迹分割为 K 个语义片段，识别每段的子目标。
- 运动语言化（language-as-action）：通过确定性 verbalizer Φ，将每段动作转为 3D 工作空间位移（如 "Move right <mm>; Roll downward <degrees>; Open gripper"）和 2D 图像平面投影轨迹。
- 结构化上下文 l_k 分两层：**语义推理**（子目标描述，如 "Reach for the handle of the blue mug"）+ **运动学推理**（3D 移动 + 2D 轨迹）。
- 输出为推理增强轨迹 τ_rat = {(o_t, a_t, s_t, l_k)}，汇总成演示库 D_pool。

**2. 并行双训练范式**
- 检索：基于任务指令的语言嵌入余弦相似度检索 top-1 演示（留一法），检索纯语言驱动，因此可跨具身检索。
- 输入构造：x_t = P_demo ⊕ I ⊕ o_t（检索演示前缀 ⊕ 指令 ⊕ 当前观测）。
- 并行专家架构：共享 VLM 骨干 f_θ 产出隐表示 h_t，同时送入：
  - **动作专家**：轻量 MLP 回归连续动作块 Â_t = (â_t, ..., â_{t+H-1})；
  - **空间语言专家**：原生自回归 LM 头，预测当前子任务 ŝ_t 和同一动作块的语言化运动 m̂_t（3D+2D）。
- 联合损失：**L = L_act(Â_t, A_t) + λL_lang(ĉ_t, c_t)**，其中 c_t = (s_t, Φ(A_t))，λ = 0.3。语言监督为共享表征提供语义、视觉接地与运动学三重约束。

**3. 非对称推理与缓存**
- 推理时完全移除空间语言专家（自回归解码开销为 0），只做一次骨干前向 + 轻量 MLP，输出动作块。
- 检索到的演示前缀在整个回合内固定不变，KV 缓存只在 t=1 计算一次，后续只前向当前观测，边际成本趋近于零。

## 三、实验设计

**仿真基准与数据集**
1. **LIBERO**：4 个套件（Spatial / Object / Goal / Long），每套 500 次 rollout，测分布内成功率。
2. **VLA-Arena**：11 个任务套件，分 4 类（Safety、Distractor、Extrapolation、Long Horizon），3 个难度（L0 分布内 / L1 / L2），只用 L0 训练，测试时提供一条目标任务演示，无参数更新。
3. **LIBERO-Plus**：7 个扰动轴（视角、机器人初始状态、传感器噪声、物体布局、背景、光照、语言），零样本测试。
4. **真实机器人**：6-DOF AgileX Piper 机械臂，4 个任务（笔入杯、胡萝卜入碗、积木入抽屉并关门、叠三个碗），125 条遥操作片段（71,702 帧）；外加 26 条 XR 人手演示与 26 条重定向到 Piper 的轨迹构成跨源检索池。

**对比方法**
- LIBERO：MemoryVLA、ACoT-VLA、AVA-VLA、CogVLA、Retrieval-VLA、DreamVLA，以及匹配控制基线 StarVLA-OFT（同骨干、同数据、无演示无语言监督）。
- VLA-Arena：OpenVLA-OFT、LingBot-VLA、Motus、GR00T-N1.6、Evo-Depth、π0.5。
- LIBERO-Plus：OpenVLA、π0、π0-FAST、Nora、WorldVLA、UniVLA、RIPT-VLA、StarVLA-OFT。
- 真机：StarVLA-OFT（匹配控制）+ 外部参考 π0.5（同数据微调）。

**主要结果**
- LIBERO：98.8% 平均成功率（StarVLA-OFT 为 96.6%）。
- VLA-Arena：0.63 总分，L0 0.84 / L1 0.62 / L2 0.43，远超 π0.5（0.44 总分）。
- LIBERO-Plus：85.1% vs StarVLA-OFT 75.0%，最大增益在视角扰动（+23.5）与传感器噪声（+19.7）。

## 六、主要结论与发现

1. **结构化演示显著提升 OOD 泛化**：VLA-Arena 总分 0.63 登顶，LIBERO-Plus 比匹配基线高 10.1 个百分点。
2. **演示是任务规格说明而非噪声**：去掉演示使成功率从 98.8% 跌至 62.4%，错误演示进一步跌至 44.9%——策略主动使用甚至"采信"演示内容。
3. **语言模态承载了大部分可迁移信息**：评测时纯文本演示几乎匹配完整图像+文本（LIBERO-Plus 84.4 vs 85.1），纯图像演示则明显下降（75.7），说明结构化语言抽象掉了源具身的视觉外观。
4. **跨具身演示在表征层面即可统一**：固定观测下切换 real/human/XR 演示，动作预测差异仅 0.0014–0.0016σ。
5. **推理效率可保持实时**：KV 缓存使带演示的稳态延迟仅 91ms（无缓存 183ms），移除语言专家避免了大 36 倍的解码开销。

## 七、方法亮点

- **零人工标注的成本结构**：VLM 自动分割 + 确定性 verbalizer 生成结构化推理，全程无人工参与。
- **"推理内化于权重、执行只用动作头"的非对称设计**：训练时用语言监督锻造"物理心智模型"，推理时剥离语言解码，兼顾泛化与实时性，这是对 Embodied CoT 延迟痛点的一个优雅解法。
- **跨具身迁移的表示级方案**：异构演示统一到语义子任务+接地运动的结构化表示，不要求源动作空间对齐，比 latent-action / retargeting 路线更简洁。
- **检索-训练一致性**：检索到的演示既作为 ICL 提示又配合显式的语言监督目标，提示（上下文模板）与监督（推理内化）相互增强。
- **实验因果设计严谨**：wrong-demonstration 消融、跨源单步一致性测量等设计能干净地归因组件的贡献。

## 八、不足与局限

1. **长程任务仍受限**：VLA-Arena Long Horizon 套件在 L1/L2 上所有方法均接近零，演示前缀固定导致执行漂移后无法重新规划，上下文条件化不能解决多步误差累积。
2. **对检索质量高度敏感**：错误演示使性能低于无演示基线 17.5 个百分点，在视觉/语义域移下检索鲁棒性是一个关键的未解决问题。

5. **语言监督与 OOD 鲁棒性之间的关系仍需更细粒度的刻画**：尽管 λ=0.3 的实验充分证明了语言监督在 OOD 泛化上的增益（LIBERO-Plus 85.1% vs 75.0%），但 λ=1.0 时性能回落的现象揭示了语言监督的双刃剑效应——过度强调语言一致性可能使共享表征被语言先验主导，反而削弱对视觉域移的适应性。这种"最优甜点区"的存在说明语言监督并非越多越好，其背后的机制（为什么中等权重最优）论文仅给出初步推测，缺乏表征层面的量化分析（如 CKA 相似度、语言/视觉梯度冲突度量）。

7. **"检索即关联"的思路在语义域移下缺少保护机制**：当新任务指令在语义上与检索空间中某条演示高度相似、但实际意图不同（如"将杯子放在盘子的左边" vs "将杯子放在盘子的右边"），错误的演示会主动损害策略（表5 已证明错误演示比无演示更差）。论文未提出检索置信度门控或演示与指令的一致性校验机制。

- **代码与模型**：论文未提供代码仓库链接、预训练权重或演示数据集的公开下载地址（仅说明"将在后续发布"）。动作块长度 H、语言专家架构层数等关键超参也未在正文完整列出。
- **可视化**：真机 rollout 的定性结果（如成功/失败轨迹对比）似乎未配图；VLA-Arena 中 L2 失败的模式（任务中断点）缺少系统性分析。不过，消融结果表格完整、指标统一（成功率 + 进度得分 + 延迟毫秒），整体可读性强。

## 十、对未来研究的启示

1. **"推理内化、执行剥离"范式可能类比到更多模态**：本文内化的是语言化推理，同理可推广到"规划内化于扩散模型、执行只用一步采样"等结构，只要训练目标能引导骨干表征编码对应的高层信息。
2. **演示的质量/正确性评估是测试时自适应方法的下一个关键战场**：需要在检索阶段引入演示与指令的语义一致性校验或不确定性感知门控。
3. **固定上下文的闭环问题**：任务进行中若策略偏离演示轨迹，固定前缀无法提供修正信号。一个自然的扩展是：以固定频率重新检索更合适的后续演示片段，或将演示前缀改为可更新的"在线记忆"（类似测试时训练的思想，但保持无梯度更新）。
4. **跨具身统一的表示收益可在更大规模多机器人语料上检验**：当前只在单具身跨源（真实机器人、人手、XR 都重定向到 Piper）上验证，若在跨机械臂型号、跨仿真器上训练/评测，结构化语言表示可能是弥合具身差距的有效桥梁。

## 十一、总评

这是一项方法设计巧妙、实验体系扎实的测试时自适应 VLA 工作。其核心洞察——"让策略模仿推理而非像素"——精准击中了 ICL 路线的痛点，并通过"双专家非对称训练"这一具有工程美感的架构在泛化与实时性之间取得了出色的平衡。实验执行上也体现了高度严谨性：匹配的基线控制、针对性的消融、跨源表征级一致性的干净测量，使核心结论具有很强的可信度。主要遗憾在于：真机规模有限、长程任务的系统性失败、对检索质量的脆弱依赖，以及关键实现细节的留白。总体而言，这项工作对 VLA 测试时自适应这一前沿方向做出了明确且可复现的推动。
