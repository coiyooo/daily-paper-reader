## 摘要
许多近期的机器人策略通过使用大型预训练视觉语言模型（VLM）作为动作主干来追求更强的控制。我们引入了WorldDiT，一种统一的扩散Transformer架构，它将动作生成与视觉世界建模相结合，并在没有大型预训练VLM动作主干的情况下实现了强大的性能。在训练过程中，一个单一的扩散Transformer生成连续的动作块，并从未来的相机帧中预测归一化的RGB块目标。在四个LIBERO模拟套件中，WorldDiT位于报告所有四个套件的方法中总模型参数和平均成功率的最优Pareto前沿上。这些结果为未来的扩展研究提供了一个强大的十亿参数以下基线。

## Abstract
Many recent robot policies pursue stronger control by using large pretrained vision-language models (VLMs) as the action backbone. We introduce WorldDiT, a unified diffusion transformer architecture that couples action generation with visual world modeling and achieves strong performance without a large pretrained VLM action backbone. During training, a single diffusion transformer generates continuous action chunks and predicts normalized RGB patch targets from future camera frames. Across four LIBERO simulation suites, WorldDiT lies on the reported Pareto frontier for total model parameters and mean success among methods reporting all four suites. These results provide a strong sub-billion-parameter baseline for future scaling studies.

## 2. 方法论

### 2.1 核心思想

WorldDiT 提出一种**统一的扩散 Transformer（DiT）架构**，用**一个共享骨干**同时建模：
- **连续机器人动作**（action chunks）
- **归一化 RGB patch 目标**（来自未来相机帧）

该设计将动作生成与视觉世界建模耦合，但**视觉预测目标仅在训练时提供辅助监督，推理时完全不参与**。

### 2.2 关键技术细节

- **输入构建**：给定语言指令和多视图观测上下文（主相机 + 腕部相机），使用**冻结的视觉编码器（MAE）和语言编码器（CLIP）** 提取多模态 token，可训练的机器人状态编码器单独编码手臂与夹爪状态。
- **窗口设计**：一个 10 步窗口包含 3 个观测上下文步、7 个目标动作、1 个未来归一化 RGB patch 目标。
- **RGB patch 目标构建**：将 224×224 帧划分为 16×16 patches，每个 768 维 patch 向量用自身均值/方差归一化；每个相机保留 **64 个均匀间隔 patch**，双相机共 **128 个目标 token**。损失仅施加于最后一个时间槽（来自 `i + H` 帧）。
- **训练目标**：采用 **flow matching** 框架，预测从高斯噪声到干净目标的直线路径速度。总损失为动作速度损失与 RGB patch 速度损失的加权和（权重分别为 0.1 与 0.001）。
- **推理流程**：仅走动作路径。从高斯噪声初始化，通过 **20 步 Euler 积分**求解动作速度场，生成 7 步动作块，**执行前 3 个动作**后更新上下文窗口并重新规划（receding-horizon control）。RGB patch token 和 RGB 预测头完全排除在推理图之外。

## 6. 主要结论与发现

- WorldDiT 在四个 LIBERO 套件上分别取得：**Spatial 98.0%、Object 97.0%、Goal 92.8%、Long 91.8%**，平均 **94.9%**。
- 模型总参数量 **399.084M**（含推理时必需的冻结模块），可训练参数仅 **135.107M**。
- 该点**位于所报告对比的 Pareto 前沿**上：
  - 所有成功率高于 WorldDiT 的方法，均使用更多总参数；
  - 所有参数量等于或低于 WorldDiT 的方法，成功率均更低。
- **关键发现**：**不依赖大规模预训练 VLM 作为动作骨干**，仅靠统一的扩散 Transformer 耦合动作与未来视觉预测，即可在 LIBERO 上取得与强 VLA 方法可比的性能，同时保持远低于十亿的参数量。
- **扩展含义**：统一世界-动作建模可作为跨模型容量、数据多样性与部署场景扩展的紧凑基础。

## 7. 优点

- **架构简洁统一**：动作与视觉目标共享同一个 DiT 骨干和同一 flow-matching 公式，避免了复杂的多分支设计。
- **推理高效**：视觉预测头仅在训练时使用，推理保留纯动作路径，无额外计算开销。
- **参数高效**：以不足 4 亿总参数（1.35 亿可训练）达到 94.9% 平均成功率，验证了无需大 VLM 骨干即可实现强控制。
- **低成本视觉预测目标**：采用归一化 RGB patch（而非像素级重建），在提供世界模型监督的同时避免了高维重建成本。
- **诚信披露**：明确标注了评测中因使用 300 episode 做 checkpoint 选择而非完全 held-out 的偏差风险，也说明对比分数无法统一复现，学术严谨性较好。
- **Pareto 分析视角**：以参数-性能的 Pareto 前沿作为对比框架，比单一成功率指标更具参考价值。

## 8. 不足与局限

- **缺乏消融实验**：未验证 RGB patch 预测目标带来的增益大小，难以剥离"统一训练"与"单动作训练"的贡献差异。
- **单一配置**：仅评测一个模型尺寸，未展示模型规模（如 depth/hidden size）扩展对性能的影响，无法支撑 scaling 行为结论。
- **评测偏差**：报告的平均成功率包含用于 checkpoint 选择的 300 episode/套件，非严格 held-out 的无偏估计。
- **对比公平性**：与其他方法的对比基于各原始报告数字，而非统一代码库、统一训练时长、统一推理预算下的复现结果。
- **场景局限**：仅限 LIBERO 仿真环境，未在真实机器人或多样化现实场景中验证；且所有套件为桌面操作任务，领域覆盖有限。
- **未报告关键效率指标**：缺少训练时长、推理延迟、显存占用、能耗等实际部署关心的数据。
- **无失败模式分析**：未讨论 Long 套件成功率相对较低（91.8%）的具体失败原因或错误类型。
- **未来目标较简单**：仅预测单一未来帧的 patch 目标，未涉及多步未来预测或视频级别的时序世界模型，与更强世界模型的差距未知。
