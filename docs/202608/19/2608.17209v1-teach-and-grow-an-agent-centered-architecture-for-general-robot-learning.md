## 摘要
端到端的视觉-语言-动作（VLA）模型和世界-动作模型为通用机器人提供了一条优雅的路径，但其可靠性受限于经过验证的物理覆盖范围。当不熟悉的物体、传感器、具身形态或接触超出该覆盖范围且没有经过验证的备选方案时，纠正失败需要新的机器人数据、策略更新和回归测试。这种反复出现的负担即为“再训练税”。与文本不同，具身数据通常必须通过操作机器来生成。我们提出了教与成长学习（TGL），一种面向通用机器人学习的智能体中心架构。在其一般形式中，多模态智能体将少量成功演示转化为可复用的技能块：针对有意义子目标运行的闭环行为。在新的场景中，智能体对这些技能块进行落地与组合，选择习得或几何工具，观察物理结果，并在执行偏离意图时修正路径。技能库存储可执行行为，而结构化经验记忆则记录成功、失败与修复。新任务无需针对特定任务的策略再训练即可获取。我们的LIBERO评估达到了最先进的性能；受控研究揭示了技能归纳、持续复用和智能体引导的适应。最后，我们提出教与成长的缩放定律假设：若X表示有效可复用经验，则未来任务误差与教学需求应随X的幂律趋近于不可再降的下限。因此，该架构将部署视为持续学习的阶段，在此阶段中，一个任务可使下一个任务更易学习。

## Abstract
End-to-end vision-language-action (VLA) and world-action models offer an elegant route to general-purpose robotics, but their reliability is bounded by validated physical coverage. When an unfamiliar object, sensor, embodiment, or contact falls outside that coverage and no validated fallback exists, correcting the failure requires new robot data, a policy update, and regression testing. This recurring burden is the retraining tax. Unlike text, embodied data must often be created by operating machines. We present Teach-and-Grow Learning (TGL), an agent-centered architecture for general robot learning. In its general form, a multimodal agent turns a few successful demonstrations into reusable Skill Blocks: closed-loop behaviors for meaningful subgoals. In a new scene, the agent grounds and composes these blocks, selects learned or geometric tools, observes the physical outcome, and revises the route when execution departs from intent. A Skill Library stores executable behavior, while structured Experience Memory carries forward success, failure, and repair. New tasks are acquired without task-specific policy retraining. Our LIBERO evaluation attains state-of-the-art performance; controlled studies expose skill induction, persistent reuse, and agent-directed adaptation. Finally, we propose the Teach-and-Grow scaling-law hypothesis: if X denotes effective reusable experience, future-task error and teaching demand should approach irreducible floors as power laws in X. The architecture therefore treats deployment as a period of continued learning, in which one task can make the next easier.

## 1. 论文的核心问题与整体含义

- **背景与动机**：端到端视觉-语言-动作（VLA）模型和世界-动作模型（WAM）代表了当前通用机器人学习的主流路线，其目标是用一个大规模策略模型直接完成“观察→语言→动作”的映射。然而，这类模型的可靠性受限于“已验证的物理覆盖范围”：一旦遇到未见过的物体、相机、夹爪、机器人本体或接触模式，且没有已验证的兜底方案，系统就需要采集新的机器人数据、重新训练策略并进行回归测试。
- **核心矛盾——再训练税（Retraining Tax）**：文本数据在语言模型时代之前就已大量存在，而具身数据必须通过操作真实机器人或仿真器才能产生。局部范围内的失败（比如一个新物体）在端到端单一大模型中往往需要全局更新才能修复，这一过程反复发生便构成了“再训练税”。随着部署场景扩大，这种全局更新会不断放大成本。
- **论文主张**：机器人学习不应该把每一次新知识都写进同一个模型的权重中，而应形成一种“局部能力可新增、全局行为不被重写”的架构。TGL 借鉴编程智能体（如 Codex、Claude Code）的工作方式：观察环境、形成计划、调用工具、读取结果、修正策略，直到任务完成。机器人也需要同样的组织智能。
- **整体含义**：TGL 将部署视为持续学习过程，而不是训练结束后的固定推理阶段。一个任务中学到的可复用能力，应能降低下一个任务的获取难度，从而使机器人在整个生命周期中不断成长。

## 2. 论文提出的方法论

### 2.1 总体架构：Teach-and-Grow Learning（TGL）

TGL 提出了一种以智能体（Agent）为中心的机器人学习架构。其核心循环可概括为：

\[
\text{teach}_n \to \text{compose}_n \to \text{act+check}_n \to \text{grow}_n \to \text{teach}_{n+1}
\]

- 少量成功演示提供任务结构；
- 智能体将演示归纳为可复用的 Skill Blocks；
- 在新场景中接地（grounding）、组合并执行；
- 观察物理结果，若偏离预期则修正路线；
- 成功、失败和修复经验写入持久化存储，成为后续任务的基础。

### 2.2 固定模型权重下的学习（Learning with Fixed Model Weights）

TGL 的学习不改变预训练模型参数：

\[
\theta_{n+1} = \theta_n = \theta
\]

\[
(B_{n+1}, M_{n+1}) = U(B_n, M_n, D_n, \Delta H_n)
\]

\[
H_{n+1} = H_n \cup \Delta H_n
\]

其中：

- \(\theta\)：预训练基础模型参数，保持固定；
- \(B\)：Skill Library，可执行技能库；
- \(M\)：Experience Memory，结构化经验记忆；
- \(D_n\)：当前任务的小样本教学集；
- \(H_n\)：交互历史。

新行为进入技能库，失败与修复经验进入经验记忆，模型权重不参与任务级更新。

### 2.3 Skill Blocks：可复用的闭环技能块

每个技能块表示为：

\[
b_i := \langle g_i, S_i, \rho_i, \gamma_i, \Pi_i, v_i, R_i \rangle
\]

- \(g_i\)：目标，说明该块应改变什么；
- \(S_i\)：适用范围（scope）；
- \(\rho_i\)：可复用策略；
- \(\gamma_i\)：将当前观测映射到接地变量的函数；
- \(\Pi_i\)：兼容的执行器集合（如 VLA、几何规划器、伺服控制器等）；
- \(v_i\)：结果验证函数，判定 pass / fail / inconclusive；
- \(R_i\)：有界恢复策略。

Skill Block 不是轨迹片段，而是“语义契约”：它定义一个有意义的子目标，并在当前场景中重新计算物体位姿、抓取点、路径等物理细节。

### 2.4 结构化经验记忆（Experience Memory）

每条记录为：

\[
\mu_j = \langle \text{task}, \text{context}, \text{blocks}, \text{outcome}, \text{diagnosis}, \text{repair}, \text{evidence} \rangle
\]

经验记忆记录“发生了什么、为什么发生、什么修复有效”，可供人检查与编辑，但本身不能执行动作。技能库负责“如何做”，经验记忆负责“学到了什么”。

### 2.5 动态智能体组合与工具选择

在任务执行时，智能体检索技能块并形成工作计划：

\[
\tau_t = \langle b_{i_{t,1}}, b_{i_{t,2}}, \dots, b_{i_{t,L_t}} \rangle
\]

执行一个块后：

\[
(o_{t+1}, \varepsilon_t) = \text{Run}(b_{i_{t,1}}, \pi_{i_{t,1},t}, o_t)
\]

智能体根据物理反馈决定继续、重试、更换执行器、重组剩余路径、请求教学或停止。这与“固定流程内适应动作”不同，TGL 允许在语义状态转换处显式地重组任务路径。

### 2.6 物理反馈、受控探索与定向教学

- 执行结果与预期效果一致则继续；
- 不一致时重新观察、更换路线或请求针对性示范；
- 教师示范提供初始结构，机器人的尝试暴露缺失知识，使后续教学更精准，体现“教学相长”的思想。

### 2.7 教与成长缩放定律假设

论文提出：

\[
E_{\text{future}}(X) = E_\infty + A X^{-\alpha}, \quad
D_{\text{teach}}(X) = D_\infty + B X^{-\beta}
\]

其中 \(X\) 为有效可复用经验：

\[
X_n = \sum_{h \in H_n} \omega(h; B_n, M_n)
\]

\(\omega \in [0,1]\) 根据证据可靠性、覆盖新增量、可检索性、接地有效性和与已有技能块的兼容性计算。

预测：有效可复用经验增长时，未来任务误差与教学需求应呈幂律下降，并趋向各自的不可再降下限。

## 6. 论文的主要结论与发现

- TGL 可以在不重训练任务级策略的前提下，通过技能库和经验记忆实现新任务获取。
- 少量示范足以归纳出可复用、可保存、可重载、可组合的 Skill Blocks。
- 物理反馈能有效改变智能体的后续计划，使执行过程不是固定脚本，而是动态任务路径。
- 技能库的局部扩展可以改变同一执行器的未来任务表现，说明成长不是依赖全局参数更新，而是依赖可检索、可接地、可组合的显式能力。
- 提出了“教与成长缩放定律假设”：有效可复用经验 \(X\) 增长时，未来任务误差和教学需求应呈幂律下降。该假设将机器人规模化的核心资源从“模型参数”或“离线数据集大小”转向“终身有效的可复用经验”。

## 7. 优点

- **显式经验记忆**：成功、失败、诊断、修复均以结构化文本保存，人类可检查、可修改，优于纯参数化记忆。

- **Agent 依赖第三方大模型**：实验中使用的多模态 Agent（如 gpt-5.6-sol）为外部模型，存在 API 成本、延迟、版本漂移和可复现性问题。
- **技能块归纳仍偏人工设定**：跨示范对齐、语义划分和验证仍依赖 Agent 的强语义能力，复杂真实场景中的稳健性需要更系统的评估。
- **实际部署可行性格局未证明**：论文提出“慢教师—快学生”的双速扩展，但蒸馏、快速策略学生和 Agent 回退机制仍属于未来工作，尚未实验验证。
