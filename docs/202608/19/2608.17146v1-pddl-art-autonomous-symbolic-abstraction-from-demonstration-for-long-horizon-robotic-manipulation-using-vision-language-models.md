## 摘要
基于PDDL的符号规划为长时程机器人操作提供了一个原则性框架，但构建准确的PDDL领域和问题描述仍然是一个重大瓶颈，通常需要大量的领域专业知识。我们提出了一种基于视觉语言模型（VLM）的方法，称为PDDL-ART，该框架能够从单个专家演示、自然语言任务描述以及可用高层动作名称库中自主生成特定任务的PDDL领域和问题描述。PDDL-ART不需要任何领域模板、动作签名或微调。为确保生成的描述不仅在语法上有效，而且在语义上与所演示的任务一致，PDDL-ART引入了一个在语法、语义和执行层面运行的多阶段校正流水线。执行引导校正的一个关键组成部分是符号谓词接地。PDDL-ART不单纯依赖视觉观察，而是利用现代VLM的工具使用能力，结合几何和时序推理来评估那些仅凭图像无法直接辨别的关系谓词。关键在于，模型自主决定何时调用这些工具以及如何解释其输出。我们在发动机维护和家庭领域的具有挑战性的操作任务上评估了PDDL-ART，这些任务包括需要记忆、抽象谓词推断以及与初始状态在视觉上难以区分的目标状态。PDDL-ART的平均成功率达到93.3%，而基线VLM规划器为78.3%。

## Abstract
Symbolic planning with PDDL offers a principled framework for long-horizon robot manipulation, but constructing accurate PDDL domain and problem descriptions remains a significant bottleneck, typically requiring substantial domain expertise. We present a Vision-Language Model (VLM)-based approach called PDDL-ART, a framework that autonomously generates task-specific PDDL domain and problem descriptions from a single expert demonstration, a natural language task description, and a library of available high-level action names. PDDL-ART does not require any domain templates, action signatures, or fine-tuning. To ensure the generated descriptions are not only syntactically valid but semantically aligned with the demonstrated task, PDDL-ART introduces a multi-stage correction pipeline operating at syntactic, semantic, and execution levels. A key component of execution-guided correction is symbolic predicate grounding. Instead of relying solely on visual observations, PDDL-ART leverages the tool-use capabilities of modern VLMs to incorporate geometric and temporal reasoning for evaluating relational predicates that are not directly discernible from images alone. Critically, the model autonomously determines when to invoke these tools and how to interpret their outputs. We evaluate PDDL-ART on challenging manipulation tasks in engine maintenance and household domains, including tasks that require memory, abstract predicate inference, and goal states that are visually indistinguishable from the initial state. PDDL-ART achieves an average success rate of 93.3%, compared to 78.3% for a baseline VLM-based planner.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：将“生成 PDDL”视为一个“生成 → 多级验证 → 定向修正”的闭环过程，并用 VLM 的工具调用能力弥补纯视觉推理的不足，实现符号谓词的可靠接地（grounding）。
- **输入**：专家演示（状态轨迹 ζ + RGB 图像序列 V）、自然语言任务描述 d、高层动作名库 A、相关物体集合 O_task。
- **两大组件**：
  1. **PDDLGenVLM**：负责生成 PDDL 领域与问题文件，并在 Stage 1 中进行语法和语义纠正。
  2. **PredicateEvalVLM**：负责在 Stage 2 中执行引导校正，对每个动作的前提（preconditions）与效果（effects）中的谓词，在演示和实际执行的关键帧上进行交叉验证。
- **Stage 1：语法与语义校正（不涉及真实机器人执行）**：
  - **关键帧提取**：通过近距离启发式（proximity-based heuristic）从演示中提取重要状态转移时刻的关键帧，避免冗余帧导致上下文过长。
  - **语法检查**：使用 VAL 解析器检查 PDDL 语法，将解析错误反馈给 PDDLGen 进行修正。
  - **规划可行性检查**：用 Fast Downward 求解器运行生成的任务；若返回“无解”或“空计划”，则反馈给 PDDLGen 修正。空计划意味着初始状态已满足目标，说明初始/目标条件建模错误。
  - **初始状态交叉验证**：将演示初始帧 v0 与生成的问题文件一起交给 VLM，让其识别初始状态描述与观察场景之间的不一致。
  - **计划语义检查**：将当前生成的计划与自然语言任务描述 d 交给 VLM，检查语义不对齐之处并反馈修正。
  - 每类检查最多进行一轮修正，且要求**最小化修改**，避免破坏已正确的结构。
- **Stage 2：执行引导校正（需在真实/仿真机器人上执行）**：
  - 通过动作映射函数 Λ : A → Q 将计划中的每个高层动作转成机器人实际配置序列并执行。若某动作执行失败（例如在夹持状态下仍执行 pick），则将失败信息、已成功执行的前缀、计划等反馈给 PDDLGen 进行最小修正。
  - **关键帧检测（动作对齐）**：由于没有演示的高层动作分割标签，使用**动态时间规整（DTW）子序列匹配**将计划中动作 aj 的执行轨迹与演示轨迹对齐，找到对应区间 [a, b]，取边界帧 va、vb 作为该动作执行前后的关键帧，用于谓词交叉验证：
    ```
    e_{o_j,0}^{[a:b]} = SubsequenceDTW( e_{o_j,0}^{[0:T]}, \hat{e}_{o_j,0}^{[a':b']} )
    ```
  - **谓词评估与工具使用**：PredicateEvalVLM 分别对演示关键帧和执行关键帧评估 pre(aj) 和 eff(aj) 中的所有谓词。若视觉信息不足以直接判断（如“IsHolding”“IsFastened”等关系谓词/抽象谓词），VLM 可**自主调用两类工具**：
    - **接近检查工具（Proximity Inspection Tool）**：用于几何/空间关系评估，模型需自动推断合适的输入参数（如物体对、距离阈值）。
    - **时间工具（Temporal Tool）**：用于回溯更早时间步中某个谓词的真值，解决需要“记忆”的长期任务。
  - 模型自主决定**是否调用工具、调用哪种工具、用什么参数**，并解释工具输出。
  - 若演示与执行评估结果不一致，则 PredicateEvalVLM 给出简要原因，并将该信息连同 PDDL 文件、动作 aj 和相关谓词反馈给 PDDLGen 做最终修正；若全部一致，则当前 PDDL 即为最终输出。
- **算法流程**（Algorithm 1）：初始生成 → 语法 / 可行性 / 初始状态 / 计划语义校正 → 执行计划（失败则修正）→ 对每个动作进行 DTW 对齐 → 谓词评估与交叉验证 → 若有 mismatch 则修正并重新规划 → 最终返回验证过的 ⟨D, P⟩ 和计划 π。

## 6. 论文的主要结论与发现

- PDDL-ART 能够从单个演示、自然语言描述和动作名库中**自动生成语法正确、语义对齐、可执行的 PDDL 领域与问题文件**，无需模板、动作签名或微调。
- 多阶段校正流水线（语法 → 语义 → 执行 → 谓词评估）能有效降低 PDDL 生成错误，其中执行引导的谓词交叉验证是提升计划与任务对齐度的关键。
- VLM 的工具调用能力（几何接近与时间回溯）可以弥补纯视觉谓词评估的不足，尤其对关系谓词和抽象谓词（如“IsOpenedOnce”）有效。
- 在六个任务、十次试验的平均结果中，完整 PDDL-ART（GPT-5.5）达到 **95% 规划可行性**和 **93.3% 与演示对齐的成功率**，明显优于最佳基线（VLM-PLAN (CoT) 的 78.3%），也优于仅用 stage-1 或 zero-shot 的消融版本。

## 7. 优点：方法或实验设计上的亮点

- **无需人工模板与微调**：输入信息较易获取（演示、任务描述、动作名），相比以往方法显著降低领域专家依赖。
- **多级验证**：从语法、规划可行性、初始状态、计划语义、实际执行到谓词级交叉验证，形成闭环，能捕获不同类型的错误。
- **最小化修改策略**：每次反馈仅要求修正具体问题，保留已正确的结构，减少 VLM 重写的破坏性。
- **创新的谓词接地方式**：结合 VLM 工具调用（空间/时间推理）而非仅依赖图像分类式判断，能处理视觉不可区分的状态（如“盖子被打开过”），且模型自主选择工具和参数，无需人工设定规则。
- **动作对齐方法**：用 DTW 子序列匹配将高层动作与演示轨迹段关联，摆脱对人工动作分割的依赖。
- **消融实验设计合理**：能清楚显示每个阶段（stage-1、stage-2、工具使用）的贡献，支持方法设计逻辑。
- **开放性**：声明代码和提示词将开源，有利于复现和后续研究。
