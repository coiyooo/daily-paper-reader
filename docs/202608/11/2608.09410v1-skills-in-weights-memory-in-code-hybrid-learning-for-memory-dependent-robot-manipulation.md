## 摘要
现代视觉-语言-动作（VLA）策略已获得了广泛的操作技能，但通常根据当前观察或短固定长度历史生成每个动作块。然而，现实世界的操作通常是非马尔可夫的，要求机器人从长时间交互历史中保留并推理任务相关信息以决定下一步动作。为应对这一挑战，我们提出HyMeS，一种混合学习框架，利用编码代理的推理和记忆管理能力来引导马尔可夫VLA进行记忆依赖型操作。具体而言，HyMeS通过基于梯度的模仿学习学习低级运动技能，而编码代理则通过启发式学习获得高级记忆管理策略，即从采样反馈中迭代更新一个可执行的启发式系统。此外，我们通过多模态阶段完成验证来闭环引导与执行之间的循环，利用本体感觉信号和多帧VLM判断更新记忆。与端到端的记忆增强型VLA相比，HyMeS只需针对可重用运动技能提供演示，而非针对每个依赖历史的任务配置，从而实现了数据高效组合泛化。在RoboMemArena上，HyMeS将平均累计成功率从52.5%提升至66.2%，平均任务成功率从41.3%提升至60.1%，相对pi0.5；同时在累计成功率上超越PrediMem 4.5个百分点，在任务成功率上超越14.5个百分点。

## Abstract
Modern vision-language-action (VLA) policies have acquired broad manipulation skills, but typically generate each action chunk from the current observation or a short fixed-length history. However, real-world manipulation is often non-Markovian, requiring robots to retain and reason over task-relevant information from long-horizon interaction histories to determine the next action. To address this challenge, we propose HyMeS, a hybrid learning framework that leverages the reasoning and memory-management capabilities of coding agents to steer a Markovian VLA for memory-dependent manipulation. Specifically, HyMeS learns low-level motor skills through gradient-based imitation learning, while a coding agent acquires high-level memory-management strategies through heuristic learning by iteratively updating an executable heuristic system from rollout feedback. Furthermore, we close the loop between steering and execution through multimodal stage-completion verification, which updates memory using proprioceptive signals and multi-frame VLM judgments. Compared with end-to-end memory-augmented VLAs, HyMeS requires demonstrations only for reusable motor skills rather than for every history-dependent task configuration, enabling data-efficient compositional generalization. On RoboMemArena, HyMeS improves mean cumulative success from 52.5% to 66.2% and mean task success from 41.3% to 60.1% over pi0.5, while outperforming PrediMem by 4.5 points in cumulative success and 14.5 points in task success.

## 论文总结：权重中的技能，代码中的记忆——面向记忆依赖型机器人操作的高效混合学习（HyMeS）

### 1. 核心问题与研究动机

- **背景**：现代视觉-语言-动作（VLA）模型（如 π0.5、π0.6）在物体泛化、场景适应和语言指令执行上表现优异，已具备广泛的基础运动技能。但绝大多数 VLA 本质上是马尔可夫的：每个动作块只由当前观察或极短的固定长度历史生成。
- **核心问题**：真实世界操作常是非马尔可夫的（memory-dependent），即当前观察无法决定下一步动作，必须依赖整个交互历史中保留的任务相关信息。例如一个按钮按压任务中，目标按压次数在开始时由卡片给定，但卡片随后被移除；当当前观察相同时，可能存在"继续按压"和"抬臂结束"两种互不兼容的动作，马尔可夫策略无法区分。
- **现有方法的不足**：已有的记忆增强型 VLA（如扩展上下文窗口、添加记忆模块、端到端训练历史条件策略）将记忆获取与运动学习耦合，需要对组合爆炸式的记忆配置收集大量昂贵的机器人示教数据，即使这些配置不涉及任何新技能。
- **研究目标**：提出一种将"记忆"从"技能"中解耦的方法，使 VLA 只需学习可复用的运动技能，而记忆管理策略通过学习获得，实现数据高效的组合泛化。

### 2. 方法论

#### 总体框架
HyMeS 是一种混合学习框架，核心将问题分解为两个空间中的学习：
- **权重空间**：VLA 通过梯度式模仿学习获取低级运动技能；
- **代码空间**：编码代理（coding agent）通过启发式学习，从 rollout 反馈中迭代更新可执行的启发式程序，以此获得高级记忆管理策略。

#### 问题设定
- 记忆依赖任务定义为 $\pi^*(a_t | h_t, \ell) = \pi^*(a_t | o_t, z_t, \ell)$，其中任务状态 $z_t = \phi(h_t)$ 是历史的紧凑函数，无法从当前观察 $o_t$ 单独恢复（观测被混叠）。
- 假设获得示教数据集 $D = \{(o_i, a_i, \ell_i)\}_{i=1}^N$，覆盖任务所需运动技能但不覆盖全部组合任务状态；额外可通过 rollout 收集执行轨迹与阶段级结果，但无专家动作标签。

#### 运动技能学习（权重空间）
- 以预训练 VLA（π0.5）作为初始化，采用流匹配（flow-matching）目标：$a_\tau = (1-\tau)\epsilon + \tau a$，通过最小化速度场损失 $\mathbb{E}\left[\|v_\theta(a_\tau, \tau | o, \ell) - (a - \epsilon)\|_2^2\right]$ 进行微调。
- 微调完成后策略权重 θ* 固定，后续记忆获取过程不再修改权重，也不需额外示教数据。

#### 记忆策略学习（代码空间）
- 符号记忆状态定义为 $s_t = \langle plan, \rho_t, B_t, N_t, F_t \rangle$，其中包含计划、当前阶段、任务绑定、重复事件计数和持久交互状态。
- 编码代理迭代式优化程序 $P = (C, V, U)$（约束选择规则、事件验证规则、记忆更新规则），依据 rollout 执行痕迹和阶段判决进行诊断与修正：$P^{(n+1)} = \text{Edit}(P^{(n)}, \xi_n, b_n)$。
- 开发阶段结束后，最佳程序 $P^*$ 被冻结，评估时禁用代码编辑与反思，仅实例化上下文相关规则。

#### 记忆条件动作引导（Steering）
- 当前阶段 $\rho_t$ 与符号记忆 $s_t$ 选择可微约束 $R_{\rho_t}(a, o_t; s_t)$。例如到达阶段的约束为末端位置与目标关键点的距离负值。
- 该约束的梯度被注入流匹配速度场：$\hat{v} = v_{\theta^*}(a_\tau, \tau|o_t, \ell) + \lambda_t \nabla_{a_\tau} R_{\rho_t}(a_\tau, o_t; s_t)$，引导去噪过程选择符合当前记忆状态的动作模式。
- 采用随策略接近交互区域而衰减的引导调度：$\lambda_t = \lambda_0 / (1 + \exp(\beta(p_t - p_{mid})))$，使记忆引导全局行为选择，而接触丰富的执行细节交由策略本身。

#### 多模态阶段完成验证与记忆更新（PACE）
- 提出 PACE 机制，融合两种证据：本体感觉信号（检测与动作相关的运动模式并保留持久事件）和视觉信号（Qwen3-VL-8B 多帧 VLM 判断，最多看最近 5 帧 RGB）。
- 每次查询组合判断 $d_r = e^{(r)}_{prop} \lor e^{(r)}_{vlm}$；只有当最近 w 次查询中至少 k 次支持完成时，才触发阶段切换（实验中 w=5, k=3），抑制孤立误差。
- 阶段切换后更新对应绑定、计数和持久状态，激活下一阶段的约束。整个过程无需特权环境状态或单独训练的任务完成检测模型。

### 3. 实验设计

#### Benchmark 与任务
- **仿真环境**：采用 RoboMemArena 的 12 任务修正协议（对原始 26 任务协议进行了纠正，排除了可用观察捷径解决或主要由运动失败主导的任务），共 160 个评估回合，覆盖四类记忆能力：
  - **转移任务（Transferring）**：如基于"某物体原来在何位置"的关联记忆；
  - **计数任务（Counting）**：如按卡片数字多次按压；
  - **序列任务（Sequential execution）**：按指令排列的多步骤执行；
  - **遮挡任务（Occlusion）**：目标在操作后被遮挡，需记忆绑定。
- 每个转移/计数任务 10 回合，遮挡任务 15 回合，序列任务 20 回合。
- **真实机器人**：SO-101 平台上 3 个记忆依赖任务（Observe-and-Pick-Up、Number-Guided Button Pressing、Put-Back Block），共 35 次试验。

#### 对比方法
- **π0.5**：原始的马尔可夫 VLA 策略，作为基线；
- **PrediMem**：RoboMemArena 原文提出的记忆增强基线（高层 VLM 规划器 + 近期帧与关键帧记忆），在修正后的 12 任务协议上重新评估；
- **HyMeS**：本文方法。真实实验中使用与 π0.5 相同的示教数据、微调权重，仅增加符号记忆与引导，隔离验证可执行记忆的独立效果。

#### 消融实验
在覆盖四个任务类别的 6 任务子集上进行两组消融：
- **One-shot P(0) vs. 完整程序**：验证 rollout 驱动的启发式学习是否有效；
- **视觉only / 本体感觉only / 多模态联合**：验证 PACE 双模态阶段验证的必要性。

### 6. 主要结论与发现

- **仿真结果（RoboMemArena，160 回合）**：
  - HyMeS 在**相同策略权重**下将整体 CSR 从 52.5% 提升至 66.2%，TSR 从 41.3% 提升至 60.1%，相比 π0.5；
  - 相比 PrediMem 提升 4.5 个 CSR 点（61.7% → 66.2%）和 14.5 个 TSR 点（45.6% → 60.1%）——说明 HyMeS 更有效地将阶段进展转化为完整任务成功；
  - 最大 TSR 提升出现在计数（+30.0）、转移（+26.6）、序列（+22.5）任务上；
  - 计数任务中 HyMeS 的 TSR 高于 PrediMem（50.0% vs. 36.7%）但 CSR 更低（60.3% vs. 72.2%），失败集中在早期阶段，一旦通过则后续更可靠；
  - 遮挡是最困难类别：PrediMem 的 CSR 低于反应式 π0.5（38.3% vs. 50.4%），说明不可靠的记忆会主动误导执行；HyMeS 的 CSR 与 π0.5 持平（50.6%）但 TSR 提升 7.0 点。
- **真实机器人（SO-101，35 回合）**：整体 TSR 从 25.7% 提升至 57.1%；三个任务分别提升 50.0、26.7、20.0 点，验证符号记忆支持线索保留、计数和源-位置关联。
- **消融实验**：rollout 经验提升 CSR/TSR 8.5/18.4 点；视觉+本体感觉双模态联合优于任一单独信号（对比视觉单独：+16.0 CSR / +21.7 TSR；对比本体感觉单独：+8.8 CSR / +8.4 TSR）。
- **定性与失败分析**：符号状态在每一步可读，可将失败定位到记忆更新、运动执行或事件验证环节。典型的正确记忆但执行失败包括：预抓取姿态瞄准偏差导致抓取落空、按压抖动导致多余按压、按压深度不足未被 PACE 识别。

### 7. 优点

- **方法论新颖性**：将"技能"与"记忆"解耦，分别放入权重空间和代码空间学习，解决端到端记忆增强方法需要组合式示教覆盖的核心痛点；
- **学习机制互补**：运动技能用梯度学习（数据驱动、适合接触丰富操作），记忆策略用启发式学习（利用 LLM 推理能力，处理离散组合逻辑），规避了神经记忆的可解释性和泛化问题；
- **有效的闭环机制**：PACE 多模态阶段验证（本体感觉+多帧 VLM 多数投票）使记忆更新具备容错能力，且无需特权状态或训练专用完成检测模型；
- **清晰的实验隔离**：与 π0.5 共享策略权重、示教数据和观察来验证记忆机制，使对比结果具有较强内部效度；
- **输入可解释性**：符号状态每步可读，可直接定位失败环节，支持可解释诊断和程序化修正（演示成本随可复用技能数而非任务配置数扩展）；
- **广泛适用性**：通过真实机器人实验验证了从仿真到硬件的迁移能力。

### 8. 不足与局限

- **任务适应性受限**：当前方法仅适用于历史可用紧凑符号状态表示的任务，对更开放式指令、分层/多模态记忆需求尚不支持；
- **底层技能瓶颈**：任务成功仍受运动能力和阶段完成验证双重限制——正确记忆状态和约束不保证接触丰富执行成功（实验中失败分析已证实）；
- **推理成本较高**：周期性的 VLM 查询和编码代理调用增加了推理延迟与每次回合的成本，限制实时性应用；
- **实验统计功效偏弱**：每任务回合数少，真实实验仅 3 个任务，缺少方差报告；6 任务消融子集来自每类 1-2 个任务，对遮挡类别（最困难的场景）的消融证据覆盖不足；
- **外部效度问题**：转移任务类别仅含 3 个序列任务、未全面覆盖原始 26 任务的多样性；修正协议虽增加了公平性，但排除的任务也减少了结论的泛化范围；
- **视觉验证的局限**：遮挡条件下视觉完成证据最不可靠，影响 PACE 的可靠性（HyMeS 在遮挡类的 CSR 仅与 π0.5 持平）。

### 9. 应用前景
- 该框架将记忆管理从神经网络权重中解耦，使策略调整和记忆调整可独立进行，为长时程机器人操作中"技能复用+记忆编配"提供新范式；
- 代码空间的可解释记忆也为机器人操作的调试和审计提供了新通道。
