## 摘要
机器人在每个决策步骤接收异构观测，但序列模型在如何随时间组织这些输入方面存在差异。我们提出了WorldToken，一种时间优先的策略实例化，它将每个策略时间步内的多视角图像、本体感觉和任务条件融合为一个世界令牌。一个因果时序Transformer对生成的世界令牌序列进行建模，扩散动作头生成动作块。在23个RoboCasa任务中，一个从零训练（除冻结的预训练CLIP文本编码器外）的85.3M参数策略，使用每个任务2,900个生成的演示，实现了59.45%的平均闭环成功率。对五个数据集规模、五个模型规模和两个训练种子进行的完整全因子扫描显示，额外目标域数据带来持续收益，而超过中等模型规模后收益递减。在相同检查点历史截断下，将可见历史减少到一或两个策略时间步会降低所有50个RoboCasa策略的闭环成功率。在RMBench Blocks Ranking上，将可见历史从146秒减少到8秒，评估器成功率从95%降至28%，而探索性扩展滚动则维持参考交换序列超过850秒。这些结果确立了完整WorldToken实例化的经验可行性，并表征了在所测试方案下的数据扩展和时序上下文行为。它们并未确立相对于替代序列组织的优越性，也未分离完整实现中哪些组件驱动了观察到的性能。

## Abstract
Robot policies receive heterogeneous observations at each decision step, yet sequence models differ in how they organize these inputs over time. We introduce WorldToken, a time-first policy instantiation that fuses multiview images, proprioception, and task conditioning within each policy timestep into one world token. A causal temporal Transformer models the resulting world-token sequence, and a diffusion action head generates action chunks. On 23 RoboCasa tasks, an 85.3M-parameter policy trained from scratch apart from a frozen pretrained CLIP text encoder achieves 59.45% mean closed-loop success using 2,900 generated demonstrations per task. A complete factorial sweep over five dataset sizes, five model sizes, and two training seeds shows consistent gains from additional target-domain data and diminishing returns beyond moderate model size. Under same-checkpoint history truncation, reducing visible history to one or two policy timesteps lowers closed-loop success for all 50 RoboCasa policies. On RMBench Blocks Ranking, reducing visible history from 146 to 8 seconds lowers evaluator success from 95% to 28%, while an exploratory extended rollout sustains the reference swap sequence for over 850 seconds. These results establish the empirical feasibility of the complete WorldToken instantiation and characterize its data-scaling and temporal-context behavior under the tested recipes. They do not establish superiority over alternative sequence organizations or isolate which components of the complete implementation drive the observed performance.

## 1. 核心问题与整体含义

- **研究动机**：机器人策略正从短视距反应式控制转向大规模视觉-语言-动作序列建模，但不同方法对“序列中一个 token 应该代表什么”没有统一答案。每个策略时间步往往包含多视角图像、本体感觉、语言条件等异构输入，拓扑级序列的组织方式（按模态展开、按空间展开、按生成角色展开等）会直接影响多模态融合、时序建模和动作生成之间的接口。
- **核心问题**：能否像语言模型阅读文本那样、以物理时间为顶层轴来组织机器人交互？论文提出“时间优先”（time-first）原则：将每个**策略时间步**（observation–decision–replanning event）压缩为一个**世界令牌（world token）**，再对该 world-token 序列做因果时序建模。
- **整体含义**：该工作不是宣称时间优先优于其他序列组织方式，而是将其作为一种**物理上可解释、可直接干预的接口**，用于研究数据规模、模型容量、时序上下文对模仿学习策略的影响。

## 2. 方法论

- **核心思想**：每个策略时间步先完成多模态融合，产生一个观测派生的 world token；顶层序列长度等于策略决策次数，与感知 token 数量解耦。即“一个时间步，一个令牌”。
- **整体流程**：  
  \( z_t = E_\theta(o_t),\quad h_t = T_\phi(z_{\le t}),\quad A_t \sim D_\psi(\cdot\mid h_t) \)  
  其中 \(E_\theta\) 为时间步内多模态编码器，\(T_\phi\) 为因果时序 Transformer，\(D_\psi\) 为扩散动作头。
- **模块细节**：
  - **多模态编码器**：每个相机视图经 CNN 视觉主干得到视觉 patch tokens；本体感觉与任务条件投影为向量；所有特征拼接后，使用 4 个可学习的 readout tokens 聚合信息，经 RMSNorm 和线性投影得到单一 world token。观察 token 不能查询 readout token，readout token 可查询全部。
  - **因果时序 Transformer**：基于 Qwen2 风格解码器架构（从零初始化），对 world token 序列施加因果自注意力，使用 1D RoPE 表示策略时间；历史长度由最大可见上下文 \(C\) 控制，窗口滑动时对位置重编号，因 RoPE 相对位置不变，不改变 token 间时间几何。
  - **扩散动作头**：使用 DiT 去噪器，以历史表示 \(h_t\) 和扩散步 \(k\) 通过 adaLN-Zero 调制，预测噪声；训练用 DDPM 前向加噪，推理用随机 DDPM 采样；每步生成 H 步动作块，但只执行前 \(H_{\text{exec}}\) 步，然后重新观测、重新规划。
- **默认设置**：不将历史动作 token 插入序列；环境反馈通过新的观测进入上下文；仅监督动作生成。扩展方向可加入未来观测预测或显式动作历史。

- **对比方法**：
  - 官方代码复现的 **BC-Transformer** 基线（RoboCasa 原生实现，500k 步训练），与 WorldToken 在相同数据规模（D=300）和评估注册表下比较。

  1. **5×5×2 全因子扫描**：5 个数据规模 × 5 个模型大小（44.3M、85.3M、218.8M、648.9M、1.49B）× 2 个训练种子，共 50 个策略；每个策略评估 3 次，共 172,500 个闭环 episodes。
  2. **上下文截断**：固定 checkpoint，设置 \(C_{\text{test}}\in\{1,2,5,10\}\)，评估所有 50 个策略；另训练 \(C_{\text{train}}=C_{\text{test}}\in\{1,2,5,10\}\) 的短上下文策略（D=300，218.8M）。
  3. **RMBench Blocks Ranking 上下文干预**：固定 checkpoint 和 100 个初始条件，改变最大可见历史 \(C\in\{608,288,128,64,32\}\)（覆盖 7.68–145.92 秒）。

## 6. 主要结论与发现

- **有效多任务控制**：85.3M 参数 WorldToken 在 D=2900 时达到 59.45% 平均闭环成功率（训练种子平均），218.8M 达到 60.26%，最佳单 run 62.0%；该水平进入公开报道的十亿级预训练系统范围（约 50–79%）。
- **数据扩展一致**：增加目标域数据在所有对比中降低 holdout RMSE 并提高闭环 SR；RMSE 符合幂律（指数 0.151–0.211，R²≥0.99）；从 50 到 2900 个演示，RMSE 降低 47–56.8%，SR 提高 32.7–39.3 个百分点。
- **模型容量收益集中**：44.3M→218.8M 参数可稳定降低 RMSE；218.8M 以上（648.9M、1.49B）不再稳定提升。数据越大，容量收益越集中在中低规模。
- **策略确实使用历史**：所有 50 个十步训练策略在可见历史截断为 1–2 步时 SR 均下降；5 步可见历史已能获得大部分收益。短上下文策略可适应训练上下文并恢复大部分损失。
- **长上下文支持持续有序行为**：Blocks Ranking 上可见历史由 608 降到 32 token 时，评估成功率从 95% 降至 28%，失败集中在需要多次有序交换的 episode；而延长滚动中一条轨迹完成 31 个正确交换，其中 26 个在上下文窗口开始滑动后完成，表明策略学到的是可循环的三步交换规则而非有限前缀。
- **RMSE 与 SR 互补而非互替**：二者在全球范围内同向，但在细微比较（如上下文长度 5 vs 10）时可能背离；离线动作拟合不必然转化为闭环任务成功。

## 7. 优点

- **清晰的时间优先接口**：将多模态融合与跨时间建模解耦，使“一个策略时间步 = 一个顶层位置”这一语义单位稳定，便于做受控干预和规模化研究。
- **系统性的扩展实验**：5×5×2 全因子扫描覆盖数据量、容量、种子三个维度，且每个条件使用固定数量的评估，数据点透明。
- **受控的上下文分析**：同 checkpoint 截断 + 单独训练短上下文策略，能区分“策略是否用历史”与“任务是否需要历史”；Blocks Ranking 案例进一步展示长上下文对持续有序行为的作用。
- **务实且透明的指标讨论**：区分离线 RMSE 与闭环 SR，指出二者差异来源（状态分布偏移、恢复行为、执行/评估器），并用统计和案例佐证。
- **从零训练可达竞争性能**：仅用冻结 CLIP 文本编码器、无机器人策略预训练，即在模拟基准上接近某些十亿级预训练系统，为资源受限研究提供参考。
- **良好的复现意识**：附录给出超参数来源、数据注册表、恢复状态映射、部分不可复现值的说明。

## 8. 不足与局限

- **实验边界**：仅限模拟环境，未涉及真实机器人；仅做事后模仿学习（BC），没有测试真实世界不确定性与系统级效率；未加入显式动作历史、预测式目标或主动感知。
- **比较范围有限**：未与替代序列组织（如按模态 token 展开、状态-动作交错、记忆模块等）在完全匹配条件下对比；文中的公开结果比较因协议不匹配不能作为优劣排序。
- **组件归因不足**：实验针对“完整 WorldToken 实例化”，未隔离每个组件（如 readout 数量、因果 backbone、扩散头）对最终性能的相对贡献；附录中的单锚点诊断仅作为探索性证据，服务器损坏导致部分数据无法独立重建。
- **可能的偏差风险**：
  - 超参数（如学习率）在 D=300 的校准 seed 上选择，后续未重调，可能存在对特定条件下的过拟合；
  - 检查点按计划步数选取而非 rollout 最优，不同模型容量的优化完成度可能不完全等价；
  - SR 固定种子重复的标准差较大（最大绝对范围 4.09 个百分点），小差异可能落入噪声；
  - Blocks Ranking 的最终结果使用同一开发注册表选择报告，存在一定的选择偏差风险。
- **数据恢复影响**：主扫描中 1 个 RMSE 聚合值、5 个 SR 单元格、若干任务级统计为 archived-only 或修复记录，不能完全独立核验，但作者已在附录 G 中逐一说明。
