## 摘要
人类通过保留早期动作所建立的知识，同时不断调整正在进行的动作，来执行长时程操作。相比之下，动作分块的视觉-语言-动作（VLA）策略在每次查询时都会从当前输入重复重新规划。现有方法要么通过记忆保留长期任务证据，要么通过动作重用和集成保留短期运动，导致跨查询交接不完整。我们提出了ChainVLA，一个1.2B参数的VLA策略，通过联合且可修改的执行状态链式连接连续查询。进度上下文（Progress Context）将循环工作状态（Working State）与稀疏事件记忆相结合，以携带从观察中推导的任务进度，而运动尾部（Motion Tail）将先前预测中未执行的部分输入到状态构建和动作生成中。这两个组件共同调节一个解码器，该解码器在最新观察下重新生成每个动作视界，允许携带的状态引导下一次预测而不固定它。ChainVLA在RMBench上达到62.8%的平均成功率，在四个LIBERO套件上达到98.8%的成功率，而移除运动尾部或进度上下文则使RMBench成功率分别降至11.2%和3.0%。这些不对称消融实验与运动连续性有助于保留从中推断任务进度的观察流这一观点一致。

## Abstract
Humans perform long-horizon manipulation by retaining knowledge of what earlier actions have established while continuously adapting the motion underway. By contrast, action-chunked vision-language-action (VLA) policies repeatedly replan from the current input at each query. Existing methods preserve either long-term task evidence through memory or short-term motion through action reuse and ensembling, leaving the cross-query handoff incomplete. We introduce ChainVLA, a 1.2B-parameter VLA policy that chains successive queries through a joint and revisable execution state. Progress Context combines a recurrent Working State with sparse event memory to carry observation-derived task progress, while Motion Tail feeds the preceding prediction's unexecuted continuation into state construction and action generation. Together, the two components condition a decoder that regenerates each action horizon under the latest observation, allowing the carried state to guide the next prediction without fixing it. ChainVLA reaches 62.8% average success on RMBench and 98.8% across four LIBERO suites, while removing Motion Tail or Progress Context reduces RMBench success to 11.2% and 3.0%, respectively. These asymmetric ablations are consistent with motion continuity helping preserve the observation stream from which task progress is inferred.

## 1. 核心问题与研究动机

- **背景与问题**：长时程操作任务中，人类通过保留先前动作建立的知识并持续调整当前动作来执行任务。而动作分块式视觉-语言-动作（VLA）策略在每次查询时都从当前输入重新规划，导致跨查询交接（cross-query handoff）不完整。
- **两层面歧义**：
  - **任务层面**：早期任务证据可能无法从当前视角恢复（例如 RMBench 的 Put Back Block 任务中，相同观察和指令可能对应不同历史，需要不同决策）。
  - **运动层面**：重新规划丢弃了前一次预测中未执行的延续部分，导致新预测的前缀可能与它所替代的动作不一致。
- **现有方法的不足**：
  - 记忆增强策略（如 MemoryVLA、ReMem-VLA 等）仅保留长期任务证据，不保留未执行的动作延续。
  - 基于时间集成、实时执行或原生延续的策略仅保留短期运动，无法保留早期任务证据。
- **核心研究问题**：VLA 策略如何在跨查询间同时链式传递任务进度和运动延续，同时保持对最新观察的响应能力？

## 2. 方法论

### 2.1 核心思想

ChainVLA 提出一种 **联合且可修订的执行状态（Joint and Revisable Execution State）**，由两个互补组件构成：

- **Progress Context（进度上下文）**：携带从观察中推导的任务进度，由**循环工作状态（Recurrent Working State）**与**稀疏事件记忆（Sparse Event Memory）**结合而成。
- **Motion Tail（运动尾部）**：携带前一次预测中未执行的延续部分，参与状态构建与动作生成。

每次查询时，该联合状态被读取、更新并向前传递，使独立解码的动作块形成跨查询的"链"。携带的状态作为**可修订的先验（revisable prior）**，而非固定计划。

### 2.2 关键技术细节

**状态传递形式化**：
- 查询 k 时，策略接收观察 \( o_k \)、本体感受状态 \( r_k \)、语言指令 \( \ell \)，组合为 \( x_k = (o_k, r_k, \ell) \)，预测长度 H 的动作序列 \( A_k \) 并执行前 \( h_{\text{exec}} \) 个动作。
- 执行状态定义为 \( s_k = (g_k, u_k) \)，其中 \( g_k \) 为 Progress Context，\( u_k \) 为 Motion Tail。
- 查询过渡：\( (A_k, W_k, C_{k+1}) = F_\theta(x_k, D_k, W_{k-1}, C_k, u_k) \)，且 \( u_{k+1} = \text{Tail}(A_k) \)。

**Recurrent Working State（循环工作状态）**：
- 工作状态 \( W_k = (L_k, B_k) \)，其中 \( L_k \) 为当前实时令牌（live tokens），\( B_k \) 为先前实时令牌的有界缓存。
- 学习的工作查询（working queries）通过交叉注意力处理当前多模态令牌，并结合前一个实时状态进行循环更新。
- 实时令牌直接进入策略融合，而汇总表示 \( \bar{W}_k \) 驱动事件检索。

**Sparse Event Memory（稀疏事件记忆）**：
- 事件记录 \( E_i = [V_i, S_i, T_i] \)，存储视觉特征、阶段信息和时间特征，并带有检索键与写入时间索引。
- 检索基于当前执行估计而非仅最近性：使用年龄感知的余弦相似度评分。
- 保留首个事件作为锚点，并根据阶段转换或周期规则触发写入。

**Motion Tail（运动尾部）**：
- 前一次查询预测的未执行后缀跨越查询边界直接传递。
- 通过两条模型侧路径传递：
  1. 编码为尾部令牌（tail tokens）参与工作状态构建。
  2. 作为轨迹初始化：\( eA^{(0)}_{k+1} = \mu_{k+1} + \sigma_u \epsilon_{k+1} \)，以尾部对齐的均值加噪声初始化全视界解码器状态。
- 解码器在最新观察、进度上下文和尾部令牌条件下重新生成每个视界位置，不复制或冻结任何动作。

**训练细节**：
- 按回合查询顺序展开相同的执行状态转换。
- 训练时携带的尾部被分离（detached），以 0.5 概率应用。
- 目标函数结合条件流动作目标、阶段监督（如有标注）和重叠一致性正则化器。

- **主结论**：ChainVLA 通过联合执行状态将任务进度与运动延续跨查询链式连接，达到 RMBench 62.8% 平均成功率（超过最强完整五任务覆盖方法 Mem-0 的 52.8%，且 Mem-0 为 8B+2B 参数规模），LIBERO 四套件平均 98.8%（最优或次优于多数方法）。

## 9. 未来研究方向与开放挑战

- **状态表示的可扩展性**：当前 Progress Context 的容量受限于工作缓存长度（有界）与事件记忆数量（16），面对远超现有基准的长时程任务（如跨天、跨会话操作），需要验证该有界表示是否仍能有效压缩与回忆关键信息，是否有必要引入分层或可扩展的记忆架构。
- **运动尾部在非分块策略中的适用性**：Motion Tail 的设计依赖“动作分块 + 截断执行”这一推理范式。若未来策略采用更细粒度或连续生成范式（如实时 token 级动作流），如何将“尾部”概念推广到无明确查询边界的设置，仍需研究。
- **可修订先验的置信度度量**：ChainVLA 将历史状态作为先验进行重新条件化，但未显式建模“该相信历史还是观察”的不确定性。若能够为状态附加不确定性或可学习置信门控，可能进一步提升在感知噪声或动态环境中的鲁棒性。
- **与底层控制闭环的协同**：论文在仿真中假设执行动作与环境无随机扰动，真实机器人上动作执行误差会累积，运动尾部作为“未执行部分”的语义可能失效。未来需要结合反馈控制或自适应重规划机制，使链式传递适应真实执行偏差。
- **训练与推理效率的权衡**：每次查询都需重新处理完整的数据流并更新状态，与简单重放历史的记忆方法相比计算开销更高。在边缘计算或实时机器人场景下，如何压缩状态提取与解码器计算成本，是一个工程化挑战。

## 10. 对领域的方法论启示

- **重新定义“记忆”在 VLA 中的角色**：ChainVLA 的实践表明，跨查询的连续性并不是简单地“记住过去”，而是需要区分“任务进度的结构化摘要”与“动作层面的瞬时延续”，并允许二者被修正。这为后续工作提供了一个通用框架：任何基于分块的策略都可以引入“可修订状态”作为连通各查询的枢纽。
- **诊断指标与优化目标的解耦**：论文将边界平滑度（如 CD、RMSE3）作为诊断工具而非训练损失，这一思路值得借鉴。许多研究容易将平滑性指标直接作为优化目标，反而可能牺牲任务完成率。ChainVLA 的工作证明了模型侧条件化传递比特意后处理更有效，也提醒社区应关注“为什么平滑性提升能或不能带来成功率的提升”。
- **消融设计中的控制变量意识**：作者在消融时特意将执行的历史动作作为独立输入，从而将“携带状态”与“过去动作信息”分离开。这种精细的控制在具身智能研究中较为少见，为可复现、可归因的实验提供了范例。
